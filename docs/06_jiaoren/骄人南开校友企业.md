## 一、统一模板（字段定义 + 字数上限）

> **2026-09-24 起执行「字段字数上限」体例**（完整三条填写纪律见[板块首页 §收录字段](06_jiaoren/README.md)）——各家卡片篇幅可比：既不许短到只剩公司名，也不许长到像研究报告。**上限是硬约束**，超限须压缩表述。

| # | 字段 | 填写说明 | 上限 |
|---|---|---|---|
| 1 | 主营赛道 | 统一赛道口径（生物医药 / 新能源 / 数字基础设施 / 数字零售 / 汽车零部件 …） | ≤40 字 |
| 2 | 成立时间 · 总部 | 工商注册年份 + 总部所在城市 | ≤45 字 |
| 3 | 当前阶段 | 已上市 / 拟上市 / 头部融资 / 持续经营 | ≤70 字 |
| 4 | 业务亮点 | 第三方能复述的"一句话业务亮点" | ≤60 字 |
| 5 | 创始人 / 核心校友 | 姓名（南开年级 / 院系 + 现任职务）；无校友背景时注明关联路径 | 单人 ≤120 字；多人合计 ≤190 字 |
| 6 | 核心产品 · 技术平台 | 主打产品 / 在研管线 / 技术平台 | ≤160 字 |
| 7 | 业绩与资本 | 营收利润 / 融资轮次 / 上市情况 | ≤150 字 |
| 8 | 行业殊荣 | 最近一次或最具代表性的荣誉 / 榜单 | ≤120 字 |
| 9 | 关联学院 | 创始人或核心校友对应的南开学院 | ≤30 字 |
| 10 | 公开背书 | 上市 / 政府认定 / 权威榜单 | ≤60 字 |
| 11 | 数据来源 | 卡片信息最初来源；上市校友企业附 04 专辑互链 | ≤80 字 |

> **空值写法**：数据未公开填 `——（未公开）`；身份未确认填 `——（待核实）`。
> **时间敏感内容不入卡片**：管线进展 / 订单 / 最新获奖归 04 专辑页或 [❤️ 回馈南开 · 回馈社会](06_jiaoren/回馈南开·回馈社会.md)。
