## 三、入库流程（"触发器 → 金数据 → 本页"）

### 1. 触发点（公众号）

- **监控目标：** 南开校友企业家联谊会微信公众号 `gh_xxx...`
- **触发动作：** 当公众号发布一篇"校友企业所获荣誉"新闻时，进入下一步
- **监控方式：** 江联/江联指派共建者每日 09:00 打开公众号查看；可在飞书/微信群接收推送通知

### 2. 抓取与解析（人 + AI 协作）

- **提取核心信息：** 企业名 / 创始人 / 主营赛道 / 公告原文链接 / 公布日期
- **24 小时内完成：** 由"金数据管理员"（默认江联，授权后由共建者承担）
- **校验项：** ① 创始人/校友背景是否在公开数据库中可查证；② 关联学院是否可定位；③ 是否与 `04_chuangye/Nankai_touzi.md` 14 家机构关联

### 3. 入库（金数据表单）

- **填写新表单："校友企业荣誉申报"**（金数据表单 `nktLE3` 或新建专表）
  - 字段：上节"字段定义"的 11 项
- **提交记录：** 同时上传公众号原文截图 + 第三方可查证来源

### 4. 沉淀到本页

- **每周整理一次**：由"金数据管理员"把上周新入库的 5-10 家汇总成本页"本月新增名单"
- **每月发布一次**：把本月入库合并到"总名单"+ 公众号二次推送
- **每年整理一次**：把所有入库的校友企业按"赛道 + 阶段 + 学院"重新聚类，形成《校友企业家白皮书》

## 四、阅读路径

### 给校友看

1. **找"南开校友创办/参股的企业"**：按赛道或学院筛
2. **找"南开系投资机构要看的企业"**：交叉看 `Nankai_touzi.md`
3. **找"同行/同业校友企业"**：在每张企业卡片里点"找校友"按钮直接发起 1v1 询问

### 给找工作的校友看

1. **查"校友企业荣誉申报"快讯**：每周公众号推送
2. **对接"校友企业 × 求职"通道**：每家企业详情中含"岗位"按钮 → 跳转到对应淘工吧

### 给共建者/运营者看

1. **共建者组每周飞书飞行会**：盘点新增
2. **每月发布公众号推文"本月新晋校友企业家"**
3. **每季度合并一份"年度校友企业白皮书"**
