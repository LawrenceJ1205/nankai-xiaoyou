## 一、为什么单独立这一辑

本板块的名录、[🏢 企业卡片](06_jiaoren/企业卡片.md) 与行业矩阵收的是**企业**（字段卡、回馈记录）；[🚀 南开人创业](04_chuangye/README.md) 里的「🧠 大咖说创业」「📚 知名风投谈 AI 创业趋势和避坑」收的是**外部方法论**（王兴、马斯克、纳瓦尔、YC、Jeff Dean）；这一辑只做一件事：

**把已经走到公开市场上的南开创业者，一个人一个人地看清——他是怎么做人的、做成了什么、留下了什么话。**

《左传》有"三不朽"：

> **太上有立德，其次有立功，其次有立言，虽久不废，此之谓不朽。**

借过来放到创业上，就是三个问题：

| 维度 | 问的是什么 | 对应创业者的什么 | 为什么放在骄人板块 |
|---|---|---|---|
| **立德** | 他是个什么样的人 | 底线、诚信、对员工/客户/社会的态度、关键处的取舍 | **创业先创人**。技术会过时，赛道会切换，只有"人"是长期变量 |
| **立功** | 他做成了什么事 | 技术突破、产品、产业价值、解决真问题 | 创业不是表态，是**交付**——没有立功，立德只是清谈 |
| **立言** | 他留下了什么话 | 公开可查的原话、方法论、对后学的判断 | **可被复述的才可被继承**——一句话能替一个年轻人省三年弯路 |

**三个维度是一条线，不是三顶帽子。** 顺序是：先立德（立住人）→ 再立功（做成事）→ 后立言（传下去）。所以本辑每家都按这个顺序写。

> **写作纪律**（同 [🎙️ 掌门人创业故事](06_jiaoren/南开掌门人创业故事.md)）：事实层全部可查（年报 / 招股书 / 校方新闻稿 / 权威媒体专访）；**带引号者为当事人原话，查不到就不写**；每页末尾附来源。

## 四、收录标准（4 条，宁缺毋滥）

1. **必须是上市公司**（A 股 / 港股 / 美股，含 A+H），且**南开校友是创始人或核心掌舵人**——"校友名片"（如执业所在机构）不收；**校友与企业的关系分三档并逐页标注**：校友创办兼掌舵 ／ 校友受让入股后掌舵 ／ 校友实控 · 校友掌舵（机构非校友创办），见第二节；
2. **必须有明确的南开教育背景**（就读院系与年级可查），仅"联谊会成员企业"或"南开系资本被投"**不入本辑**（归本板块名录的"口径分列"）；
3. **必须能查到公开的原话与事实**——立德、立功、立言三维，缺一维就标注缺口，**不编、不演绎**；
4. **市值与员工数以年报和交易所行情为准**，标注截至日期与来源。
5. **同一人不立第二份传**：已在 [🔬 南开人创业案例研究](04_chuangye/案例研究/README.md) 立传的公司及掌门人，本辑不再重复收录（2026-10-28 定，见第二节去重口径）。
