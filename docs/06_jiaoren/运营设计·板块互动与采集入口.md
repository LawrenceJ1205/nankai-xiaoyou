## 一、骄人 ⇄ 小友：板块互动空间（设计思考）

> **这一节解决什么问题**：骄人是“独立板块”，但它不能是孤岛——它手里握着"小友"最稀缺的三种资源：**已成就的企业家、成规模的资本、成体系的岗位**。这一节把"骄人能反哺小友什么、小友能反哺骄人什么"想清楚，重点落在 **创业（04）** 与 **允能南开人（07）** 两块。

### 5.1 定位校准：骄人是“资源池”，靠“引用 + 通道”参与平台

| 维度 | 骄人的角色 | 不做什么（划清边界） |
|---|---|---|
| 对创业（04） | 供给**导师 + 资本 + 正面案例** | 不做创业方法论 → 04 自己做 |
| 对允能南开人（07） | 供给**岗位 + 内推 + 人才回流** | 不做岗位发布与投递跟踪 → 07 自己做 |
| 对院系（05） | 供给**分院系的企业样本** | 不做院系介绍 |
| 对慈善（09） | 供给**回馈案例的"素材源"** | 不做公益项目运营 |

**机制原则**：骄人“独立板块”的定位不动摇；与其它板块的互动，靠**字段级引用**（每张卡片的 11 个字段本身就是外链锚点）与**固定通道**（导师池 / 岗位池 / 内推）来实现——骄人出人、出钱、出案例，04 与 07 出内容、出运营，各做各的、互相引用。

### 5.3 骄人 ⇄ 允能南开人：岗位池的四重耦合

允能南开人的定位是"校友企业实时岗位机会池"，**骄人企业就是池子的天然供给方**。两者在数据层面可直接耦合：

| 允能南开人需要什么 | 骄人卡片哪一字段可直接供给 |
|---|---|
| 岗位标签"行业" | 字段 1 **主营赛道** |
| 岗位标签"城市" | 字段 2 **成立时间 · 总部** |
| 岗位标签"院系" | 字段 9 **关联学院** |
| 岗位标签"届别" | 字段 5 **创始人 / 核心校友**（含届别） |
| "公司名 + 校友关系" | 字段 5 **创始人 / 核心校友** |
| 企业是否"靠谱" | 字段 10 **公开背书** |

**四重耦合设计：**

1. **岗位供给** —— 允能南开人首批洽谈的 5 家（物美 / 玖龙 / 智芯 / 易居 / 力鼎资本）之外，**本名录 16 家企业是第二批"岗位供给方**"；建议按"赛道 × 城市 × 学院"逐家排优先级（生物医药与医疗器械 10 家可优先覆盖生命科学学院、药学院、化学学院）。
2. **人才回流** —— 求职校友经骄人卡片认识企业 → 由允能南开人岗位池投递 → 入职即成为"骄人企业的南开人" → 未来反哺为学弟学妹的内推人。**骄人是入口，允能南开人是出口，入职校友是回流的水。**
3. **内推通道** —— 允能南开人"找校友内推"落地时，可直接以"骄人卡片 → 关联学院 → 同院校友"为路径：点开康希诺卡片 → 生命科学学院 → 找同院校友。
4. **反向激励** —— 骄人核心领袖开课（导师）↔ 其所在企业获得允能南开人**岗位内推优先权**（06_jiaoren README 已写"反向激励"，本名录可将其具体化为一份"企业—岗位"清单）。

## 二、企业发现入口：以"校友身价 × 企业体量"倒推（先捡西瓜）

> **这一节解决什么问题**：现行名录的收录触发点是"联谊会公众号荣誉新闻"——**被动、零星、靠运气**，容易先捡到芝麻。本节提出第二条轨道：直接站到"结果数据"（身价榜 / 市值榜 / 慈善榜）上，**用身价和企业体量倒推 11 字段**，优先把"西瓜"收进来。

### 6.1 为什么要换入口

| 维度 | 轨道 A：公众号新闻（现有） | 轨道 B：榜单倒推（新增） |
|---|---|---|
| 驱动 | 被动等推送 | 主动去筛 |
| 覆盖 | 零散、单条 | 成体系、可排序 |
| 时效 | 及时（当天） | 滞后（年度/半年） |
| 附加值 | 有现成细节 | **自带"公开背书**"（上榜即背书） |
| 产出顺序 | 先捡芝麻 | **先捡西瓜** |

**结论**：两条轨道不是替代，是互补——A 保时效与细节，B 保**覆盖面与优先级**。

### 6.2 榜单源（四类，按对南开的有用度排序）

| 类型 | 代表榜单 | 提供什么 | 对南开的用法 |
|---|---|---|---|
| **① 财富榜（含校友维度）** | 胡润百富榜 / 胡润全球富豪榜 / 福布斯中国富豪榜 / 新财富 500 富人榜 | 个人身价 + 企业 + 行业 + 总部 | **效率最高**——已有第三方加工的"按院校分组的校友首富排名"，可直接筛"南开" |
| **② 企业体量榜** | 胡润中国 500 强 / 胡润全球独角兽榜 / CB Insights | 企业市值或估值 | 未上市企业（如字节跳动）用**估值榜**补身价榜之缺 |
| **③ 行业榜** | 各赛道 TOP（小分子 CDMO TOP 25、医药工业百强、BNEF Tier 1 储能…） | 细分龙头 | **已在用**——都创、创诺即此来源 |
| **④ 慈善榜** | 胡润慈善榜 / 福布斯中国慈善榜 | 捐赠额与方向 | 与**第四部分"回馈南开"直接打通**——上榜者多为大额捐赠人 |

> **现成抓手**：`《2024 / 2025 年中国大学本科校友首富排名》`（基于胡润百富榜，按院校分组）——南开大学**连续两年位居榜首**（张一鸣 3500 亿 → 4700 亿）。这份"加工版"可直接当作筛选入口，无需自己跑全榜。

### 6.3 倒推链路（一条榜单记录 → 11 字段）

```
榜单一条记录（姓名 + 财富 + 公司 + 行业 + 总部/出生地）
   │
   ├─ 反查公司全称 ──→ 工商登记 ──→ 字段 2 成立时间 · 总部
   ├─ 反查创始人简历 ──→ 校友库 ──→ 字段 5 核心校友（届别 · 院系）
   ├─ 反查主营业务 ──→ 官网/年报 ─→ 字段 1 赛道 · 字段 4 亮点 · 字段 6 核心产品
   ├─ 反查财报/招股书/估值 ────────→ 字段 7 业绩与资本 · 字段 3 当前阶段
   ├─ 反查荣誉 ──→ 榜单排名本身即背书 → 字段 8 行业殊荣 · 字段 10 公开背书
   └─ 反查母校院系 ──────────────→ 字段 9 关联学院
```

**提速关键**：榜单**自带"公开背书"属性**——上榜即字段 8 / 10 的直接来源，不必再找第三方背书。这一步省掉约三分之一的核实工作量。

### 6.5 与现有收录标准的关系：双轨触发 + 一个字段升级建议

**双轨触发**：轨道 A（公众号新闻，保时效）+ 轨道 B（榜单倒推，保覆盖）→ 合并去重 → 按"身价 / 体量量级"排序，形成**补录队列**。

**字段升级建议**：现行 11 字段中缺少一个**量化体量字段**，导致无法排序。建议新增：

> **字段 12 · 身价 / 市值量级**——上市公司填市值，未上市填最新估值或创始人身价（注明榜单与年份）。

有了它，"先捡西瓜"才能落地为一条可执行的排序规则。

### 6.6 落地步骤

1. **筛**——从胡润 / 福布斯 / 新财富 + "各校校友首富排名"中筛出"南开"，得到候选名单；
2. **推**——每条候选跑一遍 6.3 的倒推链路，补齐 11 字段；
3. **并**——与现有 16 家合并去重（张一鸣、梁汝波、张茵、周海冰可作第一批）；
4. **排**——按字段 12 的体量量级排序，形成下一批补录队列；
5. **校**——每条按"收录标准 + 公开背书"复核，无南开渊源者按第 6 条铁律处理（如伯特利）。
