# 🏆 骄人南开校友企业 · 允公南开人

> **一句话定位**：陈列那些**已经走过创业期**、代表南开校友企业家联谊会整体形象的标杆企业——它们不是"创业榜样"，是**荣誉榜单**与**资源池**。
>
> 📖 **名字的来历**：取自南开校训「**允公允能，日新月异**」。**允公**，是把事情做到**担得起、回馈得了**——这里陈列的，正是已经走通、腾得出手反哺母校与社会的校友企业。它与 [💼 允能南开人](07_yunneng/README.md) 互为问答：**先「允能」（把本事练到机会来了接得住），后「允公」（把事业做到担得起社会责任）**。
>
> **层级**：**六大主力板块之一**。与 14 院系基础底座**分工不同**——底座收"组织与院系"，本板块收"校友企业的成就与资源"。

## 🎯 这块解决什么问题

很多人来南开小友，第一句问的不是"我能学到什么"，而是"咱们南开出过哪些厉害的企业家？"

这块就是给这个问题一个**稳定、可持续、可被引用**的回答。

- ❌ 不解决：南开人怎么创业（→ 那是 [🚀 南开人创业](04_chuangye/README.md)）
- ❌ 不解决：在校生怎么找工作（→ 那是 [💼 允能南开人](07_yunneng/README.md)）
- ✅ 解决：南开校友企业家的"成绩单 + 反哺通道"

## 📋 收录标准（4 条铁律 + 1 条口径分列）

1. **以"南开校友企业家联谊会"公众号发布的荣誉新闻为主要触发点**
   - 新闻提到校友企业获得融资/上市/获奖/重大并购/重大合作
   - 同时并行"**榜单倒推**"轨道（身价榜 / 市值榜 / 慈善榜 / 独角兽榜），详见 [企业发现入口](06_jiaoren/运营设计·板块互动与采集入口.md)
   - **补录节奏：10 家一组**（2026-09-17 起；另有**主理人直供**的不定期补录，2026-09-25 首例 2 家）——一批一编号、一批一来源、一批一核实分级，台账见 [📡 联谊会公众号名录扩容台账](06_jiaoren/联谊会公众号名录扩容台账.md)
2. **优先收录已上市/已并购/已成行业头部**的企业
   - 创业期企业 → 归 [🚀 南开人创业](04_chuangye/README.md)
   - 校友个人故事 → 归 [🌐 南开公社](02_jiayuan/gongshe/README.md)
3. **核心领袖可成为讲堂讲师**——收录即默认同意反向赋能 [📚 新知小讲堂](03_xinzhi/README.md) 与 [🚀 南开人创业](04_chuangye/README.md) 讲堂
4. **每条必有公开背书来源**（公众号链接 / 主流财经媒体 / 公司官网公告）
5. **口径分列（2026-09-14 新增）**——三种收录关系必须在卡片中写明，不可混称：
   - **校友创办**：创始人 / 核心团队为南开校友（如康希诺 · 宇学峰）
   - **联谊会成员企业 / 南开系资本被投**：创始团队非校友，关联来自联谊会与南开系资本（如**伯特利**）
   - **校友名片**：校友**执业**所在的头部机构，机构本身非校友企业（如法律轴的**中伦 / 京都 / 安理 / 金杜**）

## 📊 收录字段（11 项 · 各字段均有字数上限）

> **2026-09-24 起执行「字段字数上限」体例**——目的是让 19 张卡片**篇幅可比**：既不许一篇短到只剩公司名，也不许一篇长到像研究报告。**上限是硬约束**，超限即视为"介绍过长"，须压缩表述；**宁可少写一句，也不挤掉字段结构**。

| # | 字段 | 说明 | 上限 |
|---|---|---|---|
| 1 | **主营赛道** | 统一赛道口径（生物医药 / 新能源 / 数字基础设施 / 数字零售 / 汽车零部件 …） | ≤40 字 |
| 2 | **成立时间 · 总部** | 工商注册年份 + 总部城市 | ≤45 字 |
| 3 | **当前阶段** | 已上市 / 拟上市 / 头部融资 / 持续经营，可附代码与上市时间 | ≤70 字 |
| 4 | **业务亮点** | 第三方能复述的"一句话业务亮点" | ≤60 字 |
| 5 | **创始人 / 核心校友** | 姓名（南开年级 / 院系 + 现任职务）；无校友背景时注明关联路径 | 单人 ≤120 字；多人每人 ≤60 字、合计 ≤190 字 |
| 6 | **核心产品 · 技术平台** | 主打产品 / 在研管线 / 技术平台；一行主项 + 最多 3 条子项 | ≤160 字 |
| 7 | **业绩与资本** | 营收利润 / 融资轮次 / 上市情况 | ≤150 字 |
| 8 | **行业殊荣** | 最近一次或最具代表性的荣誉 / 榜单，最多 3 条 | ≤120 字 |
| 9 | **关联学院** | 创始人或核心校友对应的南开学院 | ≤30 字 |
| 10 | **公开背书** | 上市 / 政府认定 / 权威榜单 | ≤60 字 |
| 11 | **数据来源** | 卡片信息最初来源；**上市校友企业须附 04 专辑互链** | ≤80 字 |
| **12** | **身价 / 市值量级**（建议新增） | 排序字段——没有量化体量，"先捡西瓜"就排不出序 | — |

**三条填写纪律（2026-09-24 新增）**

1. **空值写法统一**：数据未公开填 `——（未公开）`，身份未确认填 `——（待核实）`。不得再写"暂无""待补""待核实"等散装写法。
2. **时间敏感内容不入卡片**：管线进展、订单变化、最新获奖等**短期动态**归 [🚀 南开人创业 · 上市校友企业专辑](04_chuangye/上市校友企业/README.md) 各页或 [❤️ 回馈南开 · 回馈社会](06_jiaoren/回馈南开·回馈社会.md)；卡片只留**可长期引用的档案量**——这样 19 张卡才不会"有的多一节、有的没有"。
3. **金额与市值必须标口径与截至日**（如"2026-09-17 收盘"），跨市场不合并。

## 📡 数据采集工作流（机器巡检 + 江联把关）

| 步骤 | 频率 | 责任人 | 工具 |
|---|---|---|---|
| **公众号名录扩容（10 家一组）** | **每组一次** | **江联本人** | 联谊会公众号 + 权威榜单交叉核实，结果写入 [📡 扩容台账](06_jiaoren/联谊会公众号名录扩容台账.md) |
| **公众号新动态巡检**（出候选清单） | **每周一次** | **机器巡检（平台自动）** | 关键词检索 + 主流媒体转载源交叉印证 |
| 候选清单**勾选确认**（入库 / 跳过） | 每周 | 江联本人 | 手机上看一眼候选清单，勾选即可 |
| 整理为 11 字段卡片 | 每月汇总 | 江联本人 + 公社版主 | 金数据表单 vT0qNX |
| 校验公开背书 | 每条必做 | 江联本人 | 主流财经媒体二次确认 |
| 录入本板块 + 反哺讲堂讲师池 | 每月 5 日 | 公社版主 | 直接更新 README + 通知讲师池 |
| 半年大版本更新 | 6 月 / 12 月 | 江联本人 | 整张名单重排 + 排序逻辑调整 |

> ⚠️ **一条能力边界（2026-09-20 实测）**：微信**没有**「订阅某公众号最新推送」的公开接口，任何工具都做不到"自动打开联谊会公众号看新文章"。可行的是**关键词检索式巡检**——按"南开 + 校友企业 + 荣誉 / 上市 / 融资 / 并购"等词轮询，把散落各处的动态（含腾讯新闻、今日头条、地方政府官网等转载源）捞回来。**实测有效**：2026-09-20 巡检即捞到联谊会 **2026-09-10 深圳名企参访**（走进鸿富瀚、影石创新；后者经核实**非校友企业**，不予收录）的完整记录。
>
> **两条通道并用**：① 机器每周巡检出候选 → 江联勾选；② 任何人看到好文章，**把链接丢给平台即可**（平台负责抓正文、拆字段）——这一条比自己整理快得多。
