## 🧭 小友导引

> 我们都是南开人，只是不常回去；每次回去，也多半是沿大中路潦草走一遍。
> 我们都是南开人，却很少听过**其他院系校友**记忆里的南开。
> AI 浪潮朝我们所有人一起涌来——**怎么办？**

「南开小友」就是为这几件事建的：

| 你的心思 | 去哪儿 |
|---|---|

| 想留下自己的南开，也想听听别人的南开 | 🔍 [我的南开家园](02_jiayuan/README.md) —— 写 500 字的"我的南开故事"、上"我的南开风采"短视频墙；想敞开心扉，就去 [🌐 南开公社聊吧](02_jiayuan/gongshe/README.md) |
| 怕被 AI 落下，想持续充电 | 📚 [新知小讲堂](03_xinzhi/README.md) —— 充值最前沿的 AI 认知框架；有疑问进 [🌟 淘知吧](03_xinzhi/taozhi/README.md) |
| 想做事、找资源、找资本 | 🚀 [南开人创业](04_chuangye/README.md) —— 结识南开系投资界学长，管窥全球创业大咖的心路心得；[🎯 小南创吧](04_chuangye/chuangbar/README.md) 里有创业导师值守 |
| 想找工作 / 换岗 | 💼 [淘工吧](07_taogong/README.md) —— 校友企业的真实岗位池 |
| 想回归组织 | 💬 [各地校友会](08_xiaoyouhui/README.md) —— 无论走到哪儿，都能找到南开大家庭的怀抱 |

## 📖 关于南开小友

**南开小友**是南开人的线上加油驿站——它面向"境遇不同的南开人"提供四个新圈子：

- 🎓 **回南开** —— 给离开南开多年、突然想回去看看的人

- 🚀 **做事业** —— 给想做事、找资源、找资本的人

每个圈子都有**粘合剂、独属内容、物理嵌套的聊吧**——四种人都在这里找到归属。
