# 💼 淘工吧

> **一句话定位**：校友企业的**实时岗位机会池**——按规范格式自主上架，由淘工吧统一展示给三核心板块所有想换岗 / 求职的校友。
>
> **隶属关系**：淘工吧是**外延服务板块**——它为三核心板块提供"就业出口"，本身不隶属于任何核心板块。

---

## 🌟 板块粘合剂（4 张专属内容卡）

| # | 模块 | 内容 |
|---|---|---|
| 1 | 🏢 **校友企业岗位池** | 鼓励校友企业人事部按规范格式实时更新用工需求 |
| 2 | 🎯 **岗位标签体系** | 按"行业 × 城市 × 院系 × 届别"四维标签精准推荐 |
| 3 | 🤝 **找校友内推通道** | 通过同院校友 / 同届校友优先内推 |
| 4 | 📊 **求职进度跟踪** | 简历投递 → HR 回复 → 面试 → Offer 全流程 |

---

## 📌 岗位发布规范（校友企业人事部专用）

| 项 | 要求 |
|---|---|
| **岗位名称** | 例：高级算法工程师（NLP 方向）|
| **公司名 + 校友关系** | 例：物美集团 · 张文中 1985 数学 |
| **工作地点** | 北京 / 上海 / 远程 |
| **岗位职责** | ≥ 5 条 bullet |
| **任职要求** | ≥ 5 条 bullet（学历 / 经验 / 技能）|
| **薪资范围** | 鼓励公开月薪范围或"面议" |
| **投递方式** | HR 邮箱 / 内推码 / 招聘官网 |
| **截止日期** | 例：2026-12-31 |

👉 [📤 校友企业人事部·发布岗位](https://twpitpbt.jsjform.com/f/NwtCFD)

## 🤝 政府及智库岗位（特别说明）

> 政府及智库岗位通常通过**国考 / 社招**发布，本板块**不收录**此类岗位。
>
> 如需此类岗位的内推信息，请走 **[🌐 南开公社 → 找校友](../02_jiayuan/gongshe/README.md)** 获取对应院校友的内推通道。

## 🏛️ 校方招聘对接入口（求职校友必看）⭐

> 💡 **为什么本板块保留校方入口？** 校友企业岗位之外的"校园招聘 / 选调生 / 就业系统"对求职校友同样重要——这是淘工吧**唯一**收录校方官方入口的板块。
>
> **v2.2 原则**：除淘工吧外，平台不再在其它板块收录校方官方链接——校友需要什么自己能搜到，本平台只做"已建群的校友企业岗位 + 这 4 个校方入口"。
