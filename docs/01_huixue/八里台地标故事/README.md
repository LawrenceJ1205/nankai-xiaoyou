# 🗿 八里台地标故事

> **一句话定位**：大中路是八里台校区的主干道，从东门一直走到西头，**两件最沉的东西分列两端**——路的一端是主楼北侧那口 1.937 米高的校钟，路的尽头是那块圆拱形的西南联大纪念碑。一件记着**失去**，一件记着**没有散**。

## 🧭 收录标准

1. **看得见、摸得着**——只收校区里**实物仍在**的地标。传说、旧址（如旧望海寺、旧秀山堂原物）不作独立条目，就近并入相关故事。
2. **一件地标一条时间线**——地标自己会说话：它的**材料、尺寸、铭文、位置**都是史料。所以本辑每篇都给出尺寸、字数、年份这些"硬数字"。
3. **不替古人抒情**——碑文、铭文、钟铭**全文照录**，读者自己读。凡史料有出入处，设「编者注」并列口径。

> 与 [🏛️ 解放北路洋行古建导览](01_huixue/导览专辑/解放北路洋行古建导览.md) 的分工：**那一辑在校外**（张伯苓建校之初的天津原貌，7 栋洋行 + 21 个故事）；**本辑在校内**（八里台校区），讲的是南开自己身上的两件实物。

## 🚶 建议的走法（与「八里台半日经典」路线 A 合并）

```
东门（地铁 11 号线 南开大学八里台站）
 └─ 一树园（一株大法桐，1950 年自南京移植）
     └─ 马蹄湖（北马蹄湖 · 湖心岛周恩来纪念碑）
         └─ 中心花园（严修、张伯苓纪念园 · 叶嘉莹先生纪念地）
             └─ 新开湖（"南开的眼睛"）
                 └─ 主楼前广场（周恩来总理雕像）
                     └─ ★ 主楼北侧 · 校钟（本辑第 1 篇）
                         └─ ★ 大中路尽头 · 西南联大纪念碑（本辑第 2 篇）
```

**两件实物之间步行约 10 分钟。** 建议节奏：校钟前停 10 分钟（读完钟铭 80 字），纪念碑前停 15 分钟（绕到碑阴看名字）。
