## 🧭 为什么是这五位（收录标准）

1. **双向**——不是"南开出了个名人"，而是**他们改变了南开，南开也塑造了他们**。五个人里，前两位是"造南开的人"，后三位是"南开造出来、又回来造南开的人"。
2. **有物可看**——每位都能在八里台校区找到对应的实物落点（铜像、纪念碑、研究所、纪念地），读完之后**可以带着朋友去看**。
3. **事实可查**——时间、地点、金额、事件均取自南开大学校史与公开报道；**凡史料有出入处，文中设「编者注」并列口径**，不替读者做无声的取舍。

> **收录纪律**：查不到公开来源的细节，宁可不写。本辑不接受"据说""相传"式的渲染。

## 🚶 建议的走法（半日 · 与「八里台半日经典」路线 A 合并）

从**东门**进校，沿大中路向西，一条路串起五个人：

```
东门
 └─ 中心花园 · 严修、张伯苓纪念园（第 1、2 篇 · 半身铜像）
     └─ 马蹄湖 · 湖心岛周恩来纪念碑（第 3 篇 · "我是爱南开的"）
         └─ 中心花园 · 叶嘉莹先生纪念地（第 5 篇）
             └─ 主楼后广场 · 校钟（地标专辑 · 钟高 1.937 米）
                 └─ 省身楼 · 陈省身数学研究所（第 4 篇）
                     └─ 大中路尽头 · 西南联大纪念碑（地标专辑）
```

**全程约 1.5–2 小时**，边走边讲，正好是一堂不用教材的校史课。
