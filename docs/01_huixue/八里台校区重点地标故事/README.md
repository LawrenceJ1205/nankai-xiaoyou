# 🗿 八里台校区重点地标故事

> **一句话定位**：回南开，**先看物，再看人**。大中路是八里台校区的主干道——路的一端是主楼北侧那口 1.937 米高的校钟，路的尽头是那块圆拱形的西南联大纪念碑；而在这条路的两侧、湖畔与校园深处，**还立着五处与五个人有关的地标**：两尊半身铜像、一座汉白玉纪念碑、一间四合院学舍、一幢淡绿色小楼。

## 🧭 收录标准

1. **看得见、摸得着**——只收校区里**实物仍在**的地标。传说、旧址（如旧望海寺、旧秀山堂原物）不作独立条目，就近并入相关故事。
2. **一件地标一条时间线**——地标自己会说话：它的**材料、尺寸、铭文、位置**都是史料。所以本辑每篇都给出尺寸、字数、年份这些「硬数字」。
3. **不替古人抒情**——碑文、铭文、钟铭**全文照录**，读者自己读。凡史料有出入处，设「编者注」并列口径。
4. **伟人地标同理**——五处伟人地标同样**先说物、再说人**：先给位置、形制、落成日期与「怎么看」，再讲这位先生与南开的故事；两处容易混的（如马蹄湖纪念碑与主楼前塑像），一律标出「⚠️ 别走错」。

> 与 [🏛️ 解放北路洋行古建导览](01_huixue/导览专辑/解放北路洋行古建导览.md) 的分工：**那一辑在校外**（张伯苓建校之初的天津原貌，7 栋洋行 + 21 个故事）；**本辑在校内**（八里台校区），讲的是南开自己身上的七处实物。

## 🚶 建议的走法（与「八里台半日经典」路线 A 合并）

```
东门（地铁 11 号线 南开大学八里台站）
 └─ 一树园（一株大法桐，1950 年自南京移植）
     └─ ★ 马蹄湖 · 湖心岛周恩来纪念碑（伟人地标 · 我是爱南开的）
         └─ 中心花园 · 严修、张伯苓纪念园（伟人地标 · 两尊半身铜像）
             └─ 新开湖（南开的眼睛）
                 └─ 主楼前广场（周恩来总理塑像 · 1989 年落成）
                     └─ ★ 主楼北侧 · 校钟（实物地标第 1 篇）
                         └─ ★ 迦陵学舍（伟人地标 · 东邻思源堂）
                             └─ ★ 陈省身故居「宁园」（伟人地标 · 西邻迦陵学舍）
                                 └─ ★ 大中路尽头 · 西南联大纪念碑（实物地标第 2 篇）
```

**七处走完约 1.5–2 小时。** 建议节奏：校钟前停 10 分钟（读完钟铭 80 字），纪念碑前停 15 分钟（绕到碑阴看名字），纪念园两尊像之间停 10 分钟（读基座铭文）。
