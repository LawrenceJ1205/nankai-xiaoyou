## 🧭 为什么是这五位（收录标准）

1. **双向**——不是「南开出了个名人」，而是**他们改变了南开，南开也塑造了他们**。五个人里，前两位是「造南开的人」，后三位是「南开造出来、又回来造南开的人」。
2. **有物可看**——每位都在八里台校区留下一处**实物落点**，且已按「地标词条」格式给出**位置 · 形制 · 落成日期 · 怎么看**：读完可以带着朋友直接走过去。
3. **事实可查**——时间、地点、金额、事件均取自南开大学校史与公开报道；**凡史料有出入处，文中设「编者注」并列口径**，不替读者做无声的取舍。

> **收录纪律**：查不到公开来源的细节，宁可不写。本辑不接受「据说」「相传」式的渲染。

## 🚶 建议的走法（半日 · 与「八里台半日经典」路线 A 合并）

从**东门**进校，沿大中路向西，一条路串起五个人——**每一站先看地标，再讲人**：

```
东门
 └─ ★ 北马蹄湖 · 湖心岛周恩来纪念碑（第 3 条 · 我是爱南开的）
     └─ ★ 中心花园 · 严修、张伯苓纪念园（第 1、2 条 · 两尊半身铜像）
         └─ ★ 迦陵学舍（第 5 条 · 东邻思源堂）
             └─ ★ 陈省身故居「宁园」（第 4 条 · 淡绿色二层小楼）
                 └─ 省身楼 · 陈省身数学研究所（顺路看陈省身墓碑）
```

**全程约 1.5–2 小时。** 五处地标之间步行都在 10 分钟以内，边走边讲，正好是一堂不用教材的校史课。
