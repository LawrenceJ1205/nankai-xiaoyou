# 🎓 不一样的回南开

> **一句话定位**：让每一次回南开都不再是"沿大中路走一遍"，而是一次 **校史 × 院系沿革 × 古建回望** 的沉浸式回访。

> **板块边界**：本板块只做**线下**的事——返校路线、志愿导游、洋行古建导览、返校召集。
> **线上**的畅聊 / 故事 / 风采 / 兴趣小组，统归新板块 [🔍 我的南开家园](02_jiayuan/README.md)。
