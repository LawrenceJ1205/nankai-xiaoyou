# 🌟 淘知吧

> **隶属关系**：← 本聊吧隶属于 **📚 [新知小讲堂](03_xinzhi/README.md)** 板块（三核心板块之一）

> **一句话定位**：新知小讲堂的"课后答疑 + AI 时代知识二手流转"园区。每月两场导师直播答疑、每周三上午"淘知精选 10 问"推送，让每一节 AI 课都有人接着聊。

---

## 🎯 这里有什么？

| 板块 | 用途 | 频次 |
|---|---|---|
| 💬 **课程同步答疑** | 直播 / 录播过程中的提问与回应 | 每节小鹅通专题课后 24h 内 |
| 🔄 **知识二手流转** | 把 AI 学习成果用于本职岗位（产品 / HR / 销售 / 运营 / 教师 / 律师） | 自由投稿 |
| 👥 **找搭子 / 组局** | 同城市校友组"AI 工具共学小组" | 持续 |
| 🎥 **直播答疑专场** | 每月 2 场 90 分钟导师值班 | 每月 2 场（首期参考 PPT 第 4 页） |

## 💡 我要提问（模板）

```
淘知吧·我的提问

1. 我的身份（届别 / 学院 / 现职）
2. 我的具体场景（产品经理 / HR / 销售 / 教师 / 律师 / 其他）：
3. 我试图解决的问题（一句话）：
4. 我已经尝试过的方法（≥ 1 项）：
5. 我希望导师给出什么样的回答：
   □ 一次性方案  □ 决策框架  □ 工具清单  □ 推荐阅读
6. 是否愿意加入"校友共学小组"：□是 □否

提交渠道：淘知吧微信群 + 小鹅通"训练营·讨论区"
```
