## 〇、口径说明（底稿自陈）

「清华系」分三层：① 创始人／掌门人为清华毕业的上市公司（**嫡系**）；② 清华实验室成果转化、2026 年新上市的 AI 公司（**智谱、商汤**）；③ 清华控股历史孵化的传统科技上市公司（**紫光股份、同方**，现已混改，仅作「清华基因」标注、不夸大控制权）。人物学历以公开资料为准。

## 一、总体格局：清华系是「底座型」打法

与复旦（产业应用）、浙大（金融＋视觉）不同，清华系上市公司的特点是从底层算力、基座模型到 Agent 平台**全栈贯通**。央媒概括为「算力—模型—场景」金字塔：清微智能（芯片底座）→ 智谱（基座模型）→ 星动纪元（具身应用）；而美团、商汤、同方则把 Agent 大规模落到企业内部和业务流程（底稿归纳）。

## 二、嫡系与上市 AI 公司案例（重点）

### 1. 美团（3690.HK）· 王兴（清华电子工程系 2001 届）——CatPaw 全场景 AI Agent

王兴保送清华电子工程系无线电专业，2001 年本科毕业。美团自研 LongCat 大模型，2026 年 7 月搭载 LongCat 2.0（总参 1.6T、1M 上下文，底稿称**首个在五万张国产算力卡上全流程训练的万亿模型**）发布全场景 Agent 平台 CatPaw。

- **内部规模**：累计覆盖 9 万员工、搭建 Agent 3 万个，多端（移动／PC／云端 7×24）协作，支持多 Agent 自主并发、对话即交付 Excel／报告／代码；
- **业务沉淀**：把门店评价诊断、商品文案、营销物料、活动策划、经营数据分析封装为「专家与技能」；Managed Agents 提供企业级数字员工，@ 即唤醒、扫码即用；
- **产学研**：与清华共建数智生活联合研究中心，智能调度技术已用于外卖配送路线优化。

### 2. 智谱 Z.AI（02513.HK）· 唐杰团队（清华计算机系 KEG 实验室转化）——全球首家 AGI 基座模型上市公司

2026 年 1 月登陆港交所，由清华计算机系知识工程实验室（KEG）成果转化。走 Chat→Coding→Agent→Co-work 阶梯，2026 上半年重心在 Coding 到 Co-work。

- **业绩**（2026H1）：总收入约 9.54 亿元（同比近 +400%）；开放平台及 API 收入 8.25 亿元（同比 +2735.7%），占比升至 86.5%；
- **平台规模**：MaaS 平台用户超 740 万（较年初 +144%），付费日活 +603%，前十大用户日均调用 +98 倍；Token 调用量较年初 +40 倍，API 均价反升约 101%；
- **Agent 能力**：GLM-5.2／5.3 主攻长程任务，100 万上下文；网络安全 CyberGym 84.5 分；GLM Coding Plan 订阅制编码智能体；国产芯片规模化推理，单 Token 成本较年初降 80%。

### 3. 商汤科技（0020.HK）· 徐立（清华系学者创业）——「一套模型＋一座 Token 工厂＋一套智能体管控系统」

2026 上半年首次实现 IFRS 盈利，提出「三个一」体系。

- **业绩**：收入 29.1 亿元（+23.4%），生成式 AI 收入 23.3 亿元（占近 80%），经常性收入 11.4 亿，IFRS 盈利 6.2 亿元；海外收入 +127%；
- **Token 工厂**：2026 年 7 月日均 Token 服务量 2.4 万亿（同比约 +22 倍），总算力 4.8 万 P；算电协同 Agent 负荷预测准确率 96%，累计节电超 1200 万元；
- **智能体落地**：办公智能体「小浣熊」服务联想、平安科技、三大电信运营商、京东、麒麟软件，总用户 +5 倍、企业用户 +6 倍、云端月活近 +10 倍；视频生成智能体 Seko 单日视频 1 万分钟、累计播放破 15 亿；个人「咔皮」系列用户破 4500 万；企业客户超 1000 家、覆盖 20+ 行业。

### 4. 同方股份（600100.SH）——数智员工平台（清华基因 · 现混改）

清华控股历史孵化（现混改）。2025 年 12 月上线数智员工系列平台，依托私有化部署大模型，融合 AI 智能体，构建智能办公、智慧客服、移动协同的企业智能中枢，配套知识管理、数据中台、决策驾驶舱。

### 5. 紫光股份（000938.SZ，新华三）——AI 基础设施＋Agent 共研（清华基因 · 现混改）

清华控股历史孵化（现混改）。旗下新华三发布 UniPoD S80000 超节点（32–1024 卡）等七大智算产品；2026 年 10 月与腾讯云签署 AI Agent 共研，推动从个人工具到组织引擎。紫光计算机另推出企业级智能体平台 UltiMind 1.0——「说话就造出自己想要的工具」。

## 三、清华系非上市但值得标注的 AI 力量（供参照）

- **清微智能**（尹首一，清华集成电路学院）：可重构 AI 芯片累计出货超 3000 万颗，TX8 落地十余座智算中心，2026 年 3 月启动上市征程；
- **星动纪元**：清华唯一持股的人形机器人企业，估值破百亿，累计订单超 5 亿元；
- **月之暗面**（Kimi，杨植麟）、**百川智能**（王小川）：清华系实验室出身的基座模型公司，未上市。

## 五、对照启示与对南开校友怎么用（⚪ 本页归纳收尾）

底稿的对照框架（承接站内已有的四组样本）：

- 字节：**平台生态**；物美：**单零售深耕**；复旦系：**产业应用＋硬科技**；浙大系：**金融 AI＋视觉大模型**；清华系：**底座全栈**——芯片→基座模型→Agent 平台→具身，是唯一打通「算力—模型—任务交付」全链条的派系，且率先出现 AGI 基座模型上市公司（智谱）和首次盈利的多模态公司（商汤）。
- 底稿对校友创业的启示：清华路线门槛最高（需算力与基座能力），但其「卖端到端任务结果、按结果计价」的 Co-work 方向，代表了 Agent 商业化的终局形态；非技术背景校友更适合在美团式「行业专家＋技能封装」、商汤式办公／垂直 Agent 应用层切入。

⚪ **本页对南开校友的三条读法**（非底稿内容）：

1. **「底座全栈」是镜子不是作业**——清华系靠 KEG／集成电路学院实验室＋清华控股历史孵化的产业链纵深，南开帮不必也不应复制；但智谱「Chat→Coding→Agent→Co-work」的阶梯，恰好给 [33 篇 AI 前沿认知和方法论](03_xinzhi/AI前沿认知和方法论/README.md) 里各家反复讲的「从工具到结果责任」提供了一条上市公司的实证时间线。
2. **美团 CatPaw 的「专家与技能」封装，是零售与服务校友可直接对号的一层**——门店诊断、文案、营销、经营分析封装成可 @ 即唤醒的数字员工，与物美（[张文中案例（2）](04_chuangye/案例研究/张文中案例研究（2）·物美拥抱数字化变革.md)）的门店智能体集群是同一件事的两种实现：一个平台自研、一个 OS 外购，**路径可以不同，封装逻辑相同**。
3. **智谱「API 均价反升 101%」值得单独读**——用量涨 40 倍的同时单价不降反升，说明 Agent 时代的定价权开始从「卖 Token」转向「卖结果」；对照 [行业推演 · 会计与律师遇上 AI 智能体](03_xinzhi/AI前沿认知推演案例/行业推演·会计与律师遇上AI智能体.md) 中「变便宜／变贵」清单，这是「判断变贵」一侧的最新上市公司证据。
