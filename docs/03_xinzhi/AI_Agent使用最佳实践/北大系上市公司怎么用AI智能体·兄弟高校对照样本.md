## 〇、口径说明（底稿自陈）

「北大系」分三层：① 创始人／掌门人为北大毕业的上市互联网／科技公司（**嫡系**）；② 北大校友创办、2025–2026 新上市的 Agent 公司（**明略**）；③ 北大校友创业但尚未上市的旁证（**面壁、银河通用等，不计入上市主体**）。人物学历以公开资料为准。蔚来李斌（北大社会学）因主要是智能车／智能座舱、Agent 证据弱，底稿自行剔除、不强行纳入。

## 一、总体格局：北大系是「应用 Agent＋搜索底座」打法

与清华「芯片—基座模型」全栈不同，北大系上市公司的特点是：一家搜索大厂（百度）做「芯云模体」全栈底座，一家 2025 年新上市的营销 Agent 公司（明略）把企业级 Agent 商业化跑通，教育／内容类校友公司则把 AI 嵌入垂直业务。**整体偏应用层、交付结果、行业落地，而非自研基座模型**（底稿归纳）。

## 二、嫡系与上市 AI 公司案例（重点）

### 1. 百度（BIDU／09888.HK）· 李彦宏（北大信息管理系 1991 届）——「芯云模体」全栈＋智能组织

百度是国内最早布局 AI 的大厂，2026 年明确把「智能组织」作为下一幕，搭子、伐谋、秒哒等智能体矩阵成体系。

- **业绩**（2026Q2）：总营收 313 亿元；核心 AI 驱动业务收入 125 亿元（+25%），占一般性业务收入 50%、连续两季过半；AI 云基础设施收入 73 亿（+50%），GPU 云 +283%；
- **通用智能体「百度搭子」**：2026 年 3 月发布，5 个月迭代 150 次；月活 674.3 万（环比 +1063.79%）；60% 用户任务跨 ≥3 步、86% 任务有明确交付终点；企业版已发 15 个套件、96 个技能，覆盖金融财务、商务法务、产品研发、运营人力；
- **垂类智能体**：自我演化超级智能体「伐谋」超 3000 家企业申请；无代码「秒哒」累计 4000 万用户、孕育 500 万个应用、市占 33.4% 居第一；「一见」视觉 AI 落地 20+ 行业数百家头部企业；
- **组织内化**：总部日均活跃智能体从 5000 个增至 3.7 万个；底层「芯云模体」覆盖芯片（昆仑芯）、云、文心大模型、Agent 平台、行业应用。

### 2. 明略科技（02718.HK）· 吴明辉（北大数学 2000 级本、计算机系硕士、在读博士）——「全球 Agentic AI 第一股」

2025 年 11 月登陆港交所，股票代码 2718（取自然常数 e≈2.718）。

- **业绩**（2026H1）：收入 7.60 亿元（+18.0%）；智能体化服务（Agentic Services）收入 1.71 亿元，同比 +605.7%，占比升至 22.5%，新客占比 68%；期内亏损 0.64 亿、收窄 68.5%；
- **核心产品**：GUI 操控模型 Mano（Mind2Web、OSWorld 两大全球基准第一）；商业数据分析智能体 DeepMiner（human-in-the-loop 多智能体闭环）；开源 Agent 协作网络 Octo（「Agent 之间的互联网」）；
- **落地成效**：营销内容自动化产线单日产出数十条达标短视频，文案过稿率 80%；智能门店系统覆盖超 7.5 万家线下门店；达人营销客户复购率 90%、客单价 +2–3 倍；
- **内部 AI Native**：1800 名员工与 5100 个 Agent 通过 Octo 协作；172 个交付场景综合提效 56.1%，沉淀 359 个可复用 Skill，部分业务线人力成本降 40% 同时服务量升 40%。

### 3. 新东方（EDU／9901.HK）· 俞敏洪（北大西语系）——垂直教育 AI 平台

2026 财年自研 AI 个性化学习平台完成首期落地，基于垂直教育专属系统、适配自有教研资源（非通用大模型），并以 AI 提升教学支援与运营效率；2026 财年 Q4 营收同比 +23%。底稿注：Agent 化程度较浅，属教育垂直应用。

## 三、北大校友但未上市的旁证（供参照，不计入上市主体）

- **银河通用**（北大教授／燕缘创投系）：具身智能，累计融资超 69.6 亿元，估值超 200 亿，机器人进入工业、仓储、零售；
- **元空智能**（ChatExcel）：北大深研院在读博士生创办，2025 年连获 3 轮千万级融资，共建 AI Agent 联合实验室；

## 五、对照启示与对南开校友怎么用（⚪ 本页归纳收尾）

底稿的对照框架（承接站内已有的五组样本）：

- 清华：**芯片→基座模型→具身，全栈自研**；北大：**搜索大厂底座＋营销／办公 Agent 商业化交付**，应用层更务实，且率先跑出「按效果付费、Agentic 服务收入高增长」的上市样本（明略）；复旦偏产业应用、浙大偏金融＋视觉、物美偏单零售深耕、字节偏平台生态——**北大系最突出的是「一个超级底座（百度）＋一个纯 Agent 第一股（明略）」的组合**。
- 底稿对校友创业的启示：明略的路径最可复制——不做基座，绑定一个垂直行业（营销／客服／门店），用自有数据做洞察，再用 Agent 闭环执行、按效果付费；百度搭子企业版／秒哒则提供了「不写代码搭 Agent」的低门槛工具层。

⚪ **本页对南开校友的三条读法**（非底稿内容）：

1. **明略是「33 篇方法论」里多条判断的上市公司对账单**——「不做基座、绑定垂直行业、按效果付费」正是 [红杉「结果即服务」](03_xinzhi/AI前沿认知和方法论/Hongshan_jieguo.md) 与 [a16z 12 美元对 7000 美元鸿沟](03_xinzhi/AI前沿认知和方法论/AI时代·很多商业常识失效了.md) 的落地版：明略智能体服务收入 +605.7%、新客占比 68%，说明「按结果交付」不只是理念、已经出现在港股报表里。
2. **百度「总部日均活跃智能体从 5000 到 3.7 万」是组织内化的硬指标**——与 [麦肯锡 2.5 万个 Agent](03_xinzhi/AI_Agent使用最佳实践/麦肯锡内部怎么用AI·4万人与2.5万个Agent.md)、美团 3 万个 Agent 同属「Agent 员工比」一族；南开校友企业自评 AI 进度，不必问「用了几个模型」，先问「日均活跃 Agent 有几个」。
3. **底稿剔除蔚来的纪律值得照录**——「证据弱、不强行纳入」与本站 [骄人名录](06_jiaoren/README.md) 的甄别红线（校企合作≠校友企业、学缘须可核）是同一套功夫：**宁可少一家，不硬凑一家**。
