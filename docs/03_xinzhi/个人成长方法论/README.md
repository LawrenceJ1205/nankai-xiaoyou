# 🌱 个人成长方法论

> **所属板块**：[📚 新知小讲堂](03_xinzhi/README.md)（六大主力板块之一）
>
> **一句话定位**：把“个人成长”当作**可学习、可操作、可复现的方法论**来整理——读书法、复利思维、耐心与延迟满足、复盘、第二大脑、能量管理。
>
> **为什么设在这里**：小讲堂讲的是**AI 时代的知识**，而这个文件夹讲的是**学知识的人本身**——工具会换代，学习能力与判断力不会。
>
> **信息截至**：2026 年 10 月
