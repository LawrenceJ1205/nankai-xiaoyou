# Cloud Code 教程

## 🔍 先澄清一个概念

说“Cloud Code”之前，需要先区分清楚。Google Cloud Code是面向专业开发者的云端插件工具，和“文科生友好”完全不搭边。但中文语境里还有一个更值得关注的名字——**Claude Code**，是Anthropic推出的终端AI编程助手，2025年Andrej Karpathy提出“氛围编程”概念后，正是这个工具让零代码基础的文科生也能做出网页和应用。

## 🤔 为什么说文科生反而有优势？

文科生的三项底层能力：
1. **精准描述和结构化表达**——写提示词的能力。你会问好问题，就能让AI做对事
2. **用户洞察力**——能设计出有温度、符合需求的应用
3. **发现并定义跨学科场景**——能把文科领域的问题翻译成技术的解法

AI协作的本质就是三件事：清晰地描述需求、判断产出的品质、给具体的修改方向。这三件事，恰好是文科训练最核心的素养。

## 📚 Claude Code学习简明四步法

### 第一步：理解“思维模式”，不是学工具本身

文科生更适合从“这个工具能帮我解决什么实际困扰”开始，而不是从“它的功能有哪些”开始。

**示例：** 活动策划的推文排版太丑了——能不能用AI帮我写个网页生成？论文的参考文献格式让人头疼——能不能让AI一键帮我整理？

### 第二步：用自然语言“说”出你的需求

**不好的表达：** “帮我做个网页。”
**更好的表达：** “帮我做一个学习打卡页面，包含日期选择器、今日学习内容输入框、提交按钮，提交后显示‘打卡成功’的提示。页面背景用浅灰色，简洁风格。”

### 第三步：判断AI的产出，迭代式优化

1. AI生成初版后，先跑起来看看是否达到预期
2. 不满意的地方，用自然语言给出修正方向
3. 重复“说需求→看产出→提修改”的循环

### 第四步：周期性地建立“自己的作品集”

**入门级项目：** 个人作品集网页、个人习惯追踪器、互动式叙事小游戏

## 💡 零基础学习入门计划

| 阶段 | 时间 | 学习重点 | 产出目标 |
|------|------|---------|---------|
| 阶段一 | 第1周 | 用自然语言描述需求→AI生成初版→测试运行 | 一个功能哪怕极其简单的静态网页 |
| 阶段二 | 第2-3周 | 迭代优化，用自然语言提出修改 | 把网页进化成多个功能模块的MVP |
| 阶段三 | 第4周起 | 寻找真实场景痛点，用AI开发定制化工具 | 完成一个自己真正会用的工具 |

## 📌 小结：核心要点

- **底层逻辑**：文科生不需要成为程序员，只需要成为“会提明确需求、会判断产出质量、会迭代优化的人类决策者”
- **学习路径**：从“痛点问题”出发，用自然语言驱动AI，靠“说→生成→判断→修正”的循环推进
- **能力检验标准**：能不能用AI独立产出一个自己能用的东西
- **差异化价值**：文科生的人文洞察力 + AI的执行力
