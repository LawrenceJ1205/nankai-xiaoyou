# Hermes Agent 教程

## 🦞 “马”和“虾”，先搞清谁是谁

**Hermes Agent**（被国内圈子里亲切地叫做“爱马仕”/“马”）是AI研究团队Nous Research在2026年2月发布的开源AI智能体框架。它和前段时间很火的“Lobster”（OpenClaw，外号“龙虾”）是同赛道的两大“网红”——只不过Hermes更像一个会自己总结经验的员工，OpenClaw更像一个调用各种工具的调度中心。

## 🐎 文科生养“马”的三层天然优势

### 1. 你天然擅长“定义问题”，而非“执行指令”

Hermes的核心定位是“一个能与你共同成长的AI Agent”。它的自我进化机制特别需要用户的“问题定义”能力——文科生的“怎么说清一件事”能力，在这里能放大AI十倍效能。

### 2. 你擅长“持续关系维护”，这正是AI最不擅长的事

Hermes最具竞争力的一点就是持久化的多层记忆系统，能跨会话保存对话记录和用户偏好。从文科训练中继承的“对需求的记忆和敏感度”，能帮你做好定期的记忆检查与纠偏。

### 3. 你最能驾驭“自动进化”，而非“每次手动调教”

Hermes有一套内置的完整学习闭环：完成任务超过5步且成功后，它会自动把经验打包成一个结构化的Markdown技能卡。这个“教会徒弟、松开缰绳”的环节，需要深厚的文本素养，而非编程能力。

## 📚 Hermes Agent简明四步学习法

### 第一步：用“一键部署”，绕开所有技术阻力

从2026年4月底起，阿里云已推出Hermes Agent的一键部署镜像——预装在轻量应用服务器和无影云电脑中，零代码、全可视化，10分钟即可完成部署。

**零代码实操路径：**
1. 进入阿里云轻量应用服务器控制台
2. 点击“创建实例”→在“应用镜像”中选中“Hermes Agent官方镜像”
3. 绑定百炼平台的API Key（新用户可领超7000万Tokens免费额度）
4. 实例创建完成后，通过WebUI面板即可开始与Hermes对话

### 第二步：用日常任务“喂”出第一个技能

直接做一个真实的任务——“帮我做一份年度工作总结PPT的逐页大纲”。Hermes完成任务后会自动生成skill.md，下次“跑一下年度总结”，它直接执行整套流程。

### 第三步：“学会放手”——理解技能自动生成

Hermes会自动整理任务中的步骤、关键判断、坑点和验证方式，打包成一个结构化的Markdown技能文件，存入 `~/.hermes/skills/` 目录。

⚠️ **特别注意：** 技能生成完全依赖任务脚本的质量和准确性。文科生的核心任务是监督它的学习复盘——定期手动审查和修正生成的技能文件。

### 第四步：多端接入，沉浸体验“数字员工”

Hermes支持钉钉、飞书、微信、Telegram等15+消息平台的接入。记忆在跨平台之间是同步的——你在微信上告诉它偏好，回头在飞书上问它，会自动带上这个偏好。

## 🎯 入门学习计划

| 阶段 | 时间 | 学习重点 | 产出目标 |
|------|------|---------|---------|
| 阶段一 | 第1周 | 一键部署Hermes并完成首次对话测试 | 能跟Hermes正常对话 |
| 阶段二 | 第2-3周 | 用真实工作任务训练并提炼至少2个自动化技能 | 至少生成2个skill.md |
| 阶段三 | 第4周起 | 多端配置，让Hermes自动完成重复环节 | 每周省下至少3小时低效重复劳动 |
