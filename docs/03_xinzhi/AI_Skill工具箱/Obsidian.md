# Obsidian 教程

## 🔍 先澄清一个概念

**Obsidian**（黑曜石）不是“又一个云笔记”。它是一款装在你自己电脑里的**本地知识库**：你指定一个文件夹（它叫“库/Vault”），里面所有笔记都是**纯 Markdown 文件**——对，就是本站「南开小友」正在用的那种 .md 文件。你在站里读到的每一页，都可以原样放进 Obsidian 继续加工。它和 Notion、印象笔记的根本区别：**数据在你的硬盘上，不在任何公司的服务器上**。

## 🤔 为什么南开人（尤其文科生）反而占优？

### 1. 数据主权：文件是你的，不是平台的

Obsidian 的笔记永远不锁定在某一家的服务器里——它由 Shida Li 与 Erica Xu 于 2020 年创立，坚持本地优先、不用风险投资、靠用户付费活下去。笔记以纯文本 .md 存储，哪怕有一天 Obsidian 消失了，你的几十年笔记用任何编辑器都能打开。做学问的人最懂：**底本要攥在自己手里**。

### 2. 双向链接：像做学问一样做笔记

输入 `[[` 就能链接到另一篇笔记，系统自动生成**反向链接**与**关系图谱**。读书汇的一篇读后感、校友的一段话、一个待考证的人物，都可以互相挂接，长成你自己的“知识图谱”——这正是 03 板块「个人成长方法论」里说的**第二大脑**。

### 3. 免费、离线、跨平台

个人使用**全功能免费**，商用自 2025 年 2 月起也免费（商业许可是自愿支持项）；Windows / macOS / Linux / iOS / Android 全覆盖，没有网络照样写。付费的只有可选项：多端加密同步 Sync（约 4–5 美元/月）和把笔记发布成网站 Publish（约 8–10 美元/月）——用网盘手动同步也完全可以。

## 📚 Obsidian 简明四步学习法

### 第一步：建一个“库”，理解“一切皆 .md”

安装后第一件事是“打开某个文件夹作为库”。建议直接为你的南开笔记单开一个文件夹（比如 `南开小友笔记/`），里面随手建三篇：读书、人物、待办。你会发现每一篇就是一个 .md 文件——**你会用记事本，你就会用 Obsidian**。

### 第二步：用 `[[双链]]` 代替“文件夹归类”

传统笔记靠文件夹分类，找的时候靠回忆；Obsidian 靠链接。写读书汇稿件时顺手写 `[[延迟满足]]`，将来任何一篇提到它的笔记都会在“反向链接”面板里自动列出来。**先链接，后结构**——图谱会自己长出来。

### 第三步：用“属性 + Bases”做轻量数据库

每篇笔记顶部可以写 YAML 属性（书名 / 作者 / 评分 / 状态）。2025 年起内置的 **Bases** 核心插件能把带同一属性的笔记变成可筛选、可排序的表格和卡片视图——书单、影单、联系人跟进表，不用装任何数据库软件。

### 第四步：克制地装 2–3 个社区插件就好

社区插件目录已有数千个（2026 年口径），日历、看板、闪卡应有尽有——但插件是双刃剑，装多了维护成本陡增。建议只装当下真用得上的两三个；此外 Obsidian 已提供官方命令行（CLI），AI 智能体也能按官方开放格式（Markdown / Bases / JSON Canvas）直接操作你的库。

## 🎯 入门学习计划

| 阶段 | 时间 | 学习重点 | 产出目标 |
|------|------|---------|---------|
| 阶段一 | 第 1 周 | 建库、写 5 篇笔记、学会 `[[双链]]` 与反向链接面板 | 一个属于你的南开知识库雏形 |
| 阶段二 | 第 2-3 周 | 属性 + Bases 做一张书单/影单数据库表；每天用“每日笔记”记一段 | 一张能筛选的表 + 连续 14 天的日志 |
| 阶段三 | 第 4 周起 | 挑 2–3 个社区插件定型工作流；定期回顾图谱，把孤岛笔记连起来 | 一张有脉络的个人知识图谱 |

## 📌 一页快速参考卡

| 对比维度 | 云端笔记（Notion / 印象笔记） | Obsidian |
|---------|------------------------------|----------|
| 数据在哪 | 平台服务器，导出有损耗 | 本地 .md 纯文本，随时整体搬走 |
| 计费 | 核心功能常绑订阅 | 个人/商用免费，Sync/Publish 才付费 |
| 离线可用 | 部分功能受限 | 完全离线 |
| 组织方式 | 文件夹 + 数据库 | 双向链接 + 图谱 + Bases |
| 上手门槛 | 低（所见即所得） | 略高（要理解 .md 与 `[[ ]]`） |
| 文科生友善度 | ★★★★ | ★★★★（肯花第一周就回本） |

## 📌 小结：核心要点

- **底层逻辑**：笔记是你自己的文件，工具只是“视图”——换任何工具，笔记都在
- **学习路径**：建库 → 双链 → 属性/Bases → 克制地装插件
- **能力检验标准**：三个月后，你的图谱里能看出自己这一季度在读什么、在想什么、欠了什么
- **与本站的关系**：「南开小友」本身就是 Markdown 知识库——你在站里学的每一篇讲义，都可以收进你的库继续加工
