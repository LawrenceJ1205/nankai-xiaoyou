# Tibo（OpenAI）：交互的变革——Agent 时代的产品与分发

> **所属专辑**：[🤖 AI 前沿认知和方法论](03_xinzhi/AI前沿认知和方法论/README.md)（📚 新知小讲堂）
>
> **出处**：微信公众号「超级创新者」的两篇《交互的变革》（主理人提供 docx，无署名、无日期）。底本转述的是一场访谈——**OpenAI 核心产品负责人 Tibo Sottiaux** 在 **OpenAI DevDay 2026** 之后接受 **Lenny's Podcast（主持 Lenny Rachitsky）** 的访谈（2026-09-29 现场录制，2026-10-04 发布，约 37 分钟）。本页**照录原文、只做分段**，底本另附的 AI（千问）评论层不收录；核查要点压成文末编者注几条。
>
> **说明**：底本是中文转述稿，不是逐字原话，并带若干语音转写笔误（「Tibo／Tebow」混写、「FCP」应为「MCP」等）——本页一律照录，只在编者注里列明。

用户不再打开你，反而可能是成功了。过去 20 年做互联网产品有一套几乎通用的打法，先触达用户，再抢到注意力，然后把操作做到几乎不用学习，用户愿意点进来留下来，你才有机会交付价值。但这套逻辑有一个默认前提，真正操作软件的是人。现在这个前提开始松动了。

OpenAI 负责 ChatGPT 和 Codex 的重置之神 Tibo 说，未来互联网上的大多数操作会由 Agent 完成。他举了 Notion 的例子，Notion 开放 FCP 以后，大量 Agent 直接涌进来调用它的能力，连系统容量和成本结构都受到了冲击。注意，人还是那个有需求的人，但搜索比较、填写、调用和执行越来越多开始交给 Agent，用户没有消失，消失的可能是他的点击。

这就让互联网时代三个最熟悉的产品问题突然有了新答案。第一，怎样让用户找到你？Agent 可能根本不会搜索你的品牌。而是直接寻找能完成任务的能力。第二，怎样让 AI 尽快把事情办完？他未必关心你设计了什么，甚至不会看到你的首页。第三，怎样降低学习成本？人需要一个好用的界面，AI 更需要清楚、稳定、可调用的接口。所以未来软件可能同时有两张脸，给机器看的那面越来越像能力，给人用的那面反而越来越接近真实世界。

Tibo 在同一场访谈里说，令人愉悦的人类多模态体验今天仍然被低估了，他自己越来越依赖语音，也越来越不想面对模型选择器、推理强度这些复杂配置。为什么一个普通用户想办件事，还要先研究哪个模型适合？好的交互应该让技术复杂性推到后台，而且这还不是简单的把打字改成说话。

Tibo 讲过一个很有画面感的经历，OpenAI 的 Dev Day 现场演示前 5 分钟，他的 dot 主动提醒生产环境出故障了，他还问要不要试着帮忙修复。Tibo 没有把修复权交给他，而是找工程团队处理。但这个案例已经足够说明问题，他知道今天有重要演示，知道这场演示依赖生产系统，也知道现在的故障需要立刻提醒谁。过去我们打开软件寻找答案，未来 Agent 可能在你还没想起要打开软件时，先把问题送到你面前。真正的主动智能开始争夺的不是你的点击，而是你愿不愿意把下一步行动交给他。当然能主动提醒不等于可以擅自执行，权限责任和人工确认反而会更重要。

这就是界面变化的两极，机器那端能力越来越结构化，人这一端交互越来越自然。但对创业者来说，比界面更大的冲击可能是流量分配权要换人了。互联网时代，我们研究搜索排名，推荐算法，广告转化，想方设法把人送到自己的产品里。和 Agent 时代，一个用户可能从头到尾都没看见你的品牌，他只交代一句，帮我把这件事办好，然后 Agent 决定去调用谁，这时候你的首页再漂亮，品牌故事再动人，也未必有展示的机会。

Tebow 谈到 ChatGPT 插件生态时，给了一个很具体的信号，他们看插件的留存、任务成功情况和质量，决定哪些插件值得继续被推荐。主持人追问，这是不是意味着靠 AEO 推关键词就能争到推荐？Tebow 的回答指向了另一件事，用户有没有持续使用，插件到底有没有用。你看，产品质量正在变成分发条件，以前你得先拿到流量，再证明产品好。以后你可能要先证明任务完成的好，才能持续拿到调用。

互联网的竞争正在从强点击走向强调用，这其实也有点像我以前讲的自然决策存在感。而 Tebow 还谈到希望让被大量使用的插件参与收益分配，这仍然是生态方方向，并不意味着分成制度已经全面成熟，但方向已经很有。平台以后分配的可能不只是用户注意力，还有用户交给 Agent 的真实任务。谁能被调用？谁能把事办成？谁就更有机会参与这次价值分配。

更尖锐的是，未来一个产品失去流量，甚至不需要先失去用户，用户可能依然认可你，依然在为某种需求付费，可他的 Agent 发现另一个服务更可靠、成本更低、完成的更好，就直接绕开了你。你的用户没说要。

你的用户没说要走，但他的操作已经走了。这也是为什么 Agent 时代做产品，除了用户体验，还必须考虑机器能否找到你、调用你、信任你。而且调用量越大，可靠性、权限和单位任务成本就越现实。毕竟一天 10 个人点错按钮和 1000 个 Agent 连续执行错误操作，后果完全不同。

不过第三个变化可能会让现在很多做 Agent 产品的人更不舒服。我们今天精心搭出来的复杂工作流，很可能并不值那么多钱。跨流程、设路由、配循环，再拆出五六个 Agent 各自负责一个步骤，这在今天确实能解决问题，但 Tebow 明确说他不认为人们会一直手工配置这些循环和流程。他想要的是能持续理解目标，记住偏好，从反馈里学习，然后自己安排执行路径的系统。

他自己就经历过一个有意思的反转，做复杂任务时，他会不断增加 Agent，组成越来越大的团队。可模型一升级，一个更强的 Agent 就能接下原来好几个 Agent 的工。于是团队又缩小了，遇到更难的任务再扩张，模型继续进步再缩小，这让我们不得不重新看待一个常见误区，Agent 越多不代表智能越强，有时候 Agent 数量只是今天模型能力不足的一种补偿，今天需要 5 个 Agent 才能完成的工作，明天也许一个就能做完，当然安全审核、权限隔离、责任追溯这些真实约束不会因为模型变强就自动消失，需要警惕的是另一类东西，纯粹为了绕开模型短板而设计的复杂步骤。

Tibo 有一个很激进的提醒，如果认真想象一年后模型的能力强上 10 倍，你今天也许会用完全不同的方式构建产品，这不是确定的性能预报，而是一种产品设计的压力测试，你现在花几个月搭建的东西究竟是在解决用户长期存在的问题，还是在精心修补模型暂时做不到的事情，前者可能越做越值钱，后者可能随着一次模型升级就失去意义。围绕暂时缺陷建立的护城河，可能只是下一次模型升级前的脚手架。

而人的角色也会跟着变，当搜索、比较、操作、执行逐渐交给 Agent，人真正要负责的是提出值得解决的问题，判断什么结果才算好，以及为关键决策承担责任。Tibo 谈到未来人才时也强调了品味、用户理解和知道什么叫好，比打字速度这样的技能更重要。

所以回头看，互联网产品最熟悉的那套增长逻辑并没有凭空消失，人仍然有注意力，仍然需要好的体验，但现在多了一个过去几乎不存在的环节，有需求的人和执行任务的 Agent 可能是两个不同的使用者。过去我们想的是怎样让更多人找到我、打开我、留下来，接下来还要问一句，当用户把任务交给 Agent，他为什么会选择我？未来软件最危险的时刻可能不是用户不再需要你，而是用户依然需要这项服务。A 点却已经不需要你的产品，在这里看。

3. **一处术语笔误**：底本「Notion 开放 **FCP** 以后」应为「开放 **MCP**」（Model Context Protocol，Anthropic 提出、让模型调用外部工具与数据的开放协议，业界比作智能体世界的「USB 口」）。同句「大量 Agent 直接涌进来调用它的能力，连系统容量和成本结构都受到了冲击」——与原件说法一致：向 Agent 开放接口会带来真实的流量与成本压力。

4. **Dot 预警那个故事，原件说得更细**：预警在演示**前 5 分钟**到达，Dot 同时提出「要不要试着帮忙修复」，Tibo 拒绝、转交工程团队；**那场演示仍然失败了**，工程团队随后排查修复。也就是说：**能识别风险 ≠ 能阻止故障 ≠ 有权独自修复**——底本后半句「能主动提醒不等于可以擅自执行」正是这个意思，但前半句若读成「Dot 救了场」就与原件不符。原件另提到：部分有生产系统访问权的专门 Agent 受更严限制与监控，有的跑在单独的 Mac mini 上。

5. **两处不升格为原话**：①「**AEO**」＝ Answer Engine Optimization（面向 AI 检索的优化），对应主持人拿它类比「写对关键词就能被推荐」的追问，Tibo 的回答落在「用户会不会持续使用」；②「**用一年后强 10 倍的模型回头看今天的产品**」是他在访谈里的表述方向——**一次产品设计的压力测试，不是性能预报**。这两处底本都当引语在用，本页不把它们升格为逐字原话。

6. **三处技术性整理**（只动标点、不动用词）：① 底本「他的 dot 主动。提醒生产环境出故障了」中间多一个句号，已删；②「纯粹为了绕开模型短板而设计的复杂步骤」在底本里没有句末标点，本页按句意补一个句号；③ 底本第（1）（2）篇在「你的用户没说要」处被号方切开，「（2）」以「你的用户没说要走，但他的操作已经走了」续上——**这是号方的切分位置，本页照其顺序排**。另：末句「A 点却已经不需要你的产品，在这里看。」疑为转写串行，**照录、不臆补**。

7. **底本里有一句话不是 Tibo 说的**：「互联网的竞争正在从强点击走向强调用，这其实也有点像我以前讲的自然决策存在感」——这是**转述稿作者的自指**（承接他此前文章的用词），不是访谈里的表述。读的时候别把它算到 Tibo 头上。
