# 🧩 AI 前沿认知和方法论应用实践案例

> **所属板块**：[📚 新知小讲堂](03_xinzhi/README.md)（七大主力板块之一）
>
> **一句话定位**：把 [🤖 AI 前沿认知和方法论](03_xinzhi/AI前沿认知和方法论/README.md) 全辑方法论，用到一件真实的、具体的小事上——**先拿出工作流，再谈系统**。
>
> **与母专辑的分工**：母专辑解决「**怎么看 AI**」（认知框架）与「**谁该读**」（导读九类人）；本专辑解决「**怎么用这些认知去设计一个东西**」——从公开材料里的真实难题出发，逐步对回母专辑的方法论，落成可照抄的操作次序。
>
> **体例**：每篇一个具体场景，先摆难题的成因／累积／痛点，再给工作流，最后逐条标出用了母专辑里的哪一篇；**不建新部门、不替人做决策、不把系统建在模型今天的缺陷上**。
>
> **信息截至**：2026 年 11 月

| # | 标准 | 说明 |
|---|---|---|
