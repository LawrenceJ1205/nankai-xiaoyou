## 🎤 小讲堂开课了 ⭐

> **重要说明（2026-09 调整）**：本入口是**全平台唯一开课入口**——包括「南开人创业」板块的导师在内，所有想在小讲堂开课的校友，请从这里发起申请。
>
> *为什么统一到这里？* 因为"南开人创业"板块目前专注**方法论沉淀 + 投资机构对接**，暂不单独建讲课流水线；想开课的创业导师先借用本入口的排课、直播、回放机制，待板块成熟后再做拆分。

### 我想开课，怎么做？

| 步骤 | 动作 | 时限 |
|---|---|---|
| 1️⃣ | 扫码填「开课申请」表：提交人/课程主题/课程大纲/目标听众/期望时长 | ≤ 5 min |
| 2️⃣ | 平台审核（教务组 + 板块主理）：过 / 改 / 拒 | ≤ 3 天 |
| 3️⃣ | 排入课程表，与淘知吧「淘知精选 10 问」预热联动 | 提前 7 天 |
| 4️⃣ | 直播 / 录播：小鹅通专题课（每周五 19:00 默认档期） | 60 min |
| 5️⃣ | 课后 24h 内：发布淘知精选 10 问 + 录播回放 | 24h |
