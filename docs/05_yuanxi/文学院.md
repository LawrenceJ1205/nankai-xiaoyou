# 📝 文学院 ·


### 卡片01 · 学院名片

**摘要：** 南开文学院是中国现代文学研究的高地。源自 1921 年南开大学中文系，是南开最早建立的系科之一。拥有中国语言文学一级学科博士点与中国现当代文学国家重点学科。学科涵盖中国现当代文学、中国古代文学、汉语言文学、比较文学与世界文学、文艺学、写作学。毕业生对口党政宣传、文化传媒、出版编辑、教育培训、互联网内容创作、文旅、剧本创作等行业。

**标签：** `#中文` `#现当代文学` `#古代文学` `#比较文学` `#传播` `#南开文学`


### 卡片02 · 名师风骨

**摘要：** 从穆旦到李何林、刘叔雅，南开文学星辉璀璨，孕育了一代代文学与文化的守护者。

**正文：**
- **穆旦（1918-1977）**：著名诗人、翻译家，南开中学 / 西南联大时期校友，是"九叶诗派"代表诗人。
- **李何林（1904-1988）**：著名文学评论家、文学家，主攻鲁迅研究，长期执教南开。
- **刘叔雅（1891-1978）**：南开中文系早期教授，文言文大家。
- **陈洪**：南开文学院当代领军学者，主攻古代文学与古典文献。
- **李新宇、郝岚、刘俐俐** 等：当代南开文学院中坚学者。
- **罗振亚**：南开诗学研究中心主任，著名诗歌评论家。

**标签：** `#穆旦` `#李何林` `#刘叔雅` `#陈洪` `#南开文学`


### 卡片03 · 卓越校友

**摘要：** 南开文学校友遍布党政宣传、出版、传媒、互联网内容创作等领域，是中文系"南开文学力量"的代表。

**正文：**
- **穆旦（1918级南开中学 + 西南联大）**：现代主义诗歌奠基人之一。
- **白玉铭（南开中文系校友）**：著名出版人，曾任人民文学出版社编辑。
- **马志明（南开中文系校友）**：相声表演艺术家（家学 + 校友），曲艺界代表。
- **李银河（社会学家、作家，公共话语代表）**：曾在南开社会学任教。
- **校友传媒群**：分布在人民日报、新华社、央视、腾讯新闻、网易文学、爱奇艺等头部内容机构。

**标签：** `#穆旦` `#马志明` `#人民文学` `#白玉铭` `#内容创作`


### 卡片04 · 校友捐赠

**摘要：** 文学院获得校友与校友企业多项捐赠支持学院建设、学生培养、文化传播研究。

**正文：**

- **校友企业（互联网内容平台）**：捐资支持学院"数字人文与 AI 文学"研究方向。

- **校友作家群**：将作品版税部分回流支持学院青年学者计划。
