# 🌍 外语学院 ·


### 卡片01 · 学院名片

**摘要：** 南开外语学院是国内小语种与跨文化沟通的"南开重镇"。前身为 1919 年南开大学英文系，现已涵盖英语、日语、俄语、德语、法语、西班牙语、阿拉伯语、翻译学、外国语言学等方向。学院拥有外国语言文学一级学科博士点。毕业生对口外事翻译、跨境业务、国际新闻、互联网出海、教育、文旅、学术等行业。

**标签：** `#外语` `#翻译` `#小语种` `#外国语言文学` `#跨文化` `#南开外院` `#互联网出海`


### 卡片02 · 名师风骨

**摘要：** 从陈逵到王宏志，南开外院薪火相传，造就了无数优秀外语人才与跨文化桥梁。

**正文：**
- **陈逵（1902-1966）**：著名英语文学学者，南开大学外语学科奠基人之一。
- **李赋宁、徐继曾**等：南开外语学科早期代表性学者。
- **王宏志**：南开外院当代领军学者，专攻翻译史。
- **苗东蕾、阎国忠**等：当代南开外院中坚学者。
- **语言学家团队**：覆盖英、日、德、法、俄、西、阿等主要研究方向。

**标签：** `#陈逵` `#王宏志` `#翻译史` `#南开外院`


### 卡片03 · 卓越校友

**摘要：** 南开外院校友遍布外事外交、跨境商务、互联网出海、翻译与出版机构，是"南开外语力量"的代表。

**正文：**
- **傅莹（南开外院法语系 + 法学硕士）**：外交家，曾任外交部副部长、驻菲律宾大使、全国人大新闻发言人。
- **外交一线校友群**：在外交部、商务部、新华社国际部、人民日报海外版、CGTN 工作。
- **跨境业务校友群**：在字节跳动 TikTok、SHEIN、米哈游海外、Anker、华为海外等企业从事本地化、品牌、用户增长。
- **互联网出海校友**：在米哈游、莉莉丝、FunPlus、网易出海业务部等头部出海企业任关键岗位。
- **翻译出版群**：在外研社、外语教学与研究出版社、上海译文、人民文学等顶级出版社。

**标签：** `#傅莹` `#外交部` `#TikTok` `#SHEIN` `#翻译`
