# ⚖️ 法学院 ·


### 卡片01 · 学院名片

**摘要：** 中国法学高等教育研究基地之一。源自 1923 年南开大学法学系，复建于 1980 年代。学科涵盖法学理论、法律史、宪法学与行政法学、民商法学、刑法学、国际法学、知识产权法学。毕业生对口党政机关、律师事务所、企业法务、金融机构、知识产权机构、高校等。

**标签：** `#法学` `#法律硕士` `#宪法行政法` `#民商法` `#知识产权` `#国际法`


### 卡片02 · 名师风骨

**摘要：** 从王赣愚到高铭暄、付子堂，南开法学薪火相传，是中国法学教育版图的重要一角。

**正文：**
- **王赣愚（1920 年代南开法科）**：南开大学法科早期教师，中国早期法学教育者之一。
- **王金柱、冯大同等**：南开法学复建期学者，对外经济法、刑法基础研究奠基人。
- **高铭暄（南开法学校友）**：著名刑法学泰斗，中国人民大学法学院教授，是 1997 年《刑法》起草的重要参与者之一。
- **付子堂（南开法学博士校友）**：著名法学家，原西南政法大学校长，主攻法理学与法社会学。
- **左海聪、赵正群**：当代南开法学院的领军学者。

**标签：** `#王赣愚` `#高铭暄` `#付子堂` `#左海聪` `#南开法学`


### 卡片03 · 卓越校友

**摘要：** 南开法学校友遍布司法机关、律师事务所、企业法务、高校，在中国法治建设中发挥重要作用。

**正文：**
- **高铭暄（南开法学 1947-1951 年毕业）**：著名刑法学家、中国刑法学泰斗。
- **傅莹（南开外国语学院法语系 + 返校在南开获法学硕士）**：外交家，曾任外交部副部长、中国驻菲律宾大使、全国人大新闻发言人。
- **胡建淼（南开法学博士校友）**：行政法学领军学者之一。
- **校友律师群**：金杜、大成、君合、中伦等头部律所多有南开校友合伙人。

**标签：** `#高铭暄` `#傅莹` `#金杜` `#君合` `#中伦`


### 卡片04 · 校友捐赠

**摘要：** 法学院获得校友与校友企业捐赠支持学院科研、平台建设、学生培养。

**正文：**
- **法学院 1988 级校友**：纪念入学 30 周年，集体捐赠设立"南开法学薪火基金"。
- **校友律师群（金杜、君合、中伦等）**：捐资支持学院"模拟法庭"与"国际法辩论队"。
- **校友企业（法律科技）**：捐资支持学院"AI+法律"交叉研究。
- **付子堂奖学金**：面向青年学者。

**标签：** `#校友捐赠` `#南开法学薪火基金` `#模拟法庭` `#AI+法律`
