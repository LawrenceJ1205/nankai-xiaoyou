# 🏛️ 周恩来政府管理学院 ·


### 卡片01 · 学院名片

**摘要：** 国内政治学与公共管理学的"南开重镇"。前身为南开大学政治学系，源于南开老校长张伯苓"允公允能"的教育理念。**2023 年更名为周恩来政府管理学院**（周恩来 1919 年南开学校毕业），是国内首家以周恩来命名的政府管理学院。学科涵盖政治学、行政管理学、国际关系、社会学、社会工作。毕业生对口党政机关、智库、高校、社会组织、外事、咨询等行业。

**标签：** `#政治学` `#行政管理` `#国际关系` `#周恩来` `#南开政管` `#社会组织`


### 卡片02 · 名师风骨

**摘要：** 从张伯苓到杨敬民、杨光斌，南开政治学薪火相传，形成"中国政治学的南开学派"。

**正文：**
- **张伯苓（1876-1951）**：南开大学创办人，"允公允能、日新月异"校训提出者，是中国现代教育家与南开精神的象征。
- **杨敬民（1933-2019）**：政治学家，南开大学原副校长，奠基南开政治学学科。
- **朱光磊（1955- ）**：当代政治学家、南开大学原副校长，主攻当代中国政府与政治、当代中国社会阶层。
- **杨光斌（1970级政治系）**：著名政治学家，中国人民大学国际关系学院教授，主攻比较政治、政治学理论。
- **吴志成（1971级政治系）**：南开周恩来政府管理学院教授，主攻全球治理、国际组织。
- **王一鸣、程同顺**：当代南开政管学院的中坚学者。

**标签：** `#张伯苓` `#杨敬民` `#朱光磊` `#杨光斌` `#吴志成` `#允公允能`


### 卡片03 · 卓越校友

**摘要：** 南开政管校友遍布党政机关、国际组织、智库与高校，是当代中国"治理南开力量"的重要来源。

**正文：**
- **杨光斌（1970级政治系）**：中国人民大学国际关系学院教授，著名政治学家。
- **张蕴岭（南开政治系校友）**：著名国际问题专家，中国社会科学院学部委员，主攻亚太地区国际关系。
- **赖明（南开政治系校友）**：曾任中央国家机关有关部门负责人。
- **林尚立（南开政治系校友）**：复旦大学国际关系与公共事务学院教授，当代中国政治学者代表之一。
- **任剑涛（南开政治系校友）**：中国人民大学政治学系教授，主攻政治哲学、当代中国政府。

**标签：** `#杨光斌` `#张蕴岭` `#林尚立` `#任剑涛` `#国际关系`


### 卡片04 · 校友捐赠

**摘要：** 政管学院获得校友与校友企业多项捐赠支持学院建设、学生培养与国际交流。

**正文：**
- **周恩来政府管理学院校友基金**：由毕业 30 年、20 年、10 年校友多次集资，主要用于学生海外交流、奖助学金。
- **校友企业（南开公能投资）**：捐赠支持学院"全球治理"研究方向建设。
- **政管 1998 级校友**：纪念入学 20 周年，集体捐赠设立"公能奖学金"。
- **孙立祥**（南开政治系校友）：设立"立祥国际事务奖学金"，支持优秀学生赴联合国等国际组织实习。

**标签：** `#校友捐赠` `#公能奖学金` `#全球治理` `#国际事务`

| 操作路径 | 说明 |
|---------|------|
| 首页 → 允能南开人 → 筛选"政治/公共管理/外事" | 所有岗位由校友企业自主上架 |
| 若暂无新岗位，显示"暂无新鲜岗位，建议先找人" | 诚实展示，引导用户先建立人脉 |
