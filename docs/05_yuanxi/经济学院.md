# 📈 经济学院 · 


### 卡片01 · 学院名片

**摘要：** 中国高校第一个经济学院，百年南开经济学派。何廉创办中国第一个经济研究所、编制享誉海内外的“南开指数”。优势方向涵盖理论经济、应用经济、国际经济、数字经济，毕业生对口经济研究、金融、咨询、政府、智库、企业管理等行业。

**标签：** `#经济学` `#理论经济` `#国际经济` `#南开指数` `#数字经济`


### 卡片02 · 名师风骨

**摘要：** 何廉、方显廷并称“民国四大经济学家”，开创用计量方法研究中国社会经济问题的先例。谷书堂主编的政治经济学教科书发行逾百万册，影响几代经济学人。

**正文：**
- **何廉（1895-1975）**：中国现代经济学教育奠基人，1926年创办中国第一个经济研究所，编制享誉海内外的“南开指数”，1948年任南开代理校长。
- **方显廷（1903-1985）**：著名经济学家，与何廉、马寅初、刘大钧并称“民国四大经济学家”，开创用计量方法研究中国社会经济问题的先例。
- **陈序经（1903-1967）**：著名社会学家、经济学家，以“全盘西化论”著称，曾任南开大学副校长。
- **滕维藻（1917-2008）**：著名经济学家，南开大学原校长、经济学院首任院长，中国世界经济学会主要创始人。
- **谷书堂（1925-2016）**：著名经济学家，长期致力于社会主义经济理论研究，主编政治经济学教科书发行逾百万册，2004年三位学生同时获“孙冶方经济学奖”。
- **熊性美（1926- ）**：著名国际经济专家，南开世界经济学科重要创始人之一，执教南开60年。
- **魏埙（1920-2006）**：著名经济学家，南开政治经济学学术带头人。
- **李竞能（1924- ）**：著名人口经济学家，中国人口学开拓者之一。
- **杨敬年（1908-2016）**：著名经济学家、翻译家，中国发展经济学先行者，以107岁高龄逝世。
- **陈宗胜**：中国财富经济研究院院长，长期从事收入分配、经济发展研究。

**标签：** `#何廉` `#方显廷` `#谷书堂` `#滕维藻` `#陈序经` `#南开指数`


### 卡片03 · 卓越校友

**摘要：** 南开经济校友遍布政府、产业界与学术界，在不同领域践行“经邦济世”的南开经济学精神。

**正文：**
- **张思民（1979级）**：深圳海王集团创始人、董事长，2011年捐资1000万元设立“谷书堂经济学学术基金”。
- **周海冰（1988级数学、金融双学位，2005年获经济学博士）**：乾通科技董事长，2016年与侯莹校友共同捐赠1亿元。
- **李罗力（经济系校友）**：南开经济校友会会长，发起成立“南开经济50人论坛”。
- **文飚**：天津金茂投资董事长，2015年捐款100万元建立中国财富经济研究院发展基金。
- **王磊（1997级）**：2016年捐赠600万元设立“王磊涌泉基金”。

**标签：** `#张思民` `#周海冰` `#李罗力` `#谷书堂经济学学术基金`


### 卡片04 · 校友捐赠

**摘要：** 经济学科获得校友巨额捐赠，有力支撑了学术研究、人才培养和国际交流。

**正文：**
- **张思民**：2011年捐资1000万元设立“谷书堂经济学学术基金”，用于支持经济学基础理论研究和扶助中青年学者成长。
- **周海冰与侯莹校友**：2016年共同捐赠1亿元人民币，其中5000万元建设“海冰楼”，5000万元设立“智德基金”，支持经济学院等五个院系。
- **匿名企业家校友**：2019年南开校友企业家联谊会成立大会上，3位匿名校友捐赠1.72亿元，用于数学、大数据、AI、金融、国际经济等学科建设。
- **深圳校友会（11位校友代表）**：2019年百年校庆期间捐赠1.8亿元。
- **文飚**：2015年捐款100万元建立中国财富经济研究院发展基金。
- **王武（1992级）与李威（1984级）**：2020年捐款200万元，其中100万元在经济学院台湾经济研究所设立“彤源南开教育基金”。
- **王磊（1997级）**：2016年捐赠600万元设立“王磊涌泉基金”。

**标签：** `#校友捐赠` `#谷书堂经济学学术基金` `#海冰楼` `#智德基金` `#深圳校友会`


### 卡片05 · 新晋校友都去了哪些机构？

**摘要：** 基于公开信息整理的经济校友集中任职机构清单，供锁定目标、主动搜索和联系校友使用。

| 行业方向 | 典型机构（均有经济校友任职） |
|---------|---------------------------|
| **政府/政策研究** | 国家发改委、财政部、央行、国务院发展研究中心、各地政策研究室 |
| **智库/学术机构** | 社科院各所、中国宏观经济研究院、北大国发院、复旦经院 |
| **金融机构** | 各大银行总行、券商研究所、基金公司、保险资管 |
| **咨询公司** | 麦肯锡、波士顿咨询、贝恩、四大会计师事务所（咨询线） |
| **企业战略/管培** | 华为、腾讯、阿里、各大央企总部战略部 |
| **国际组织** | 世界银行、IMF、WTO、联合国开发计划署 |

**使用建议：** 锁定目标机构 → 打开“找校友”按机构名称搜索 → 联系在该机构任职的经济校友。

**标签：** `#校友去向` `#政府` `#智库` `#金融` `#咨询` `#国际组织`
