# 🧬 生命科学学院 ·


### 卡片01 · 学院名片

**摘要：** "中国生命科学发祥地之一"——南开大学生命科学学院。源自 1922 年南开大学生物学系，是中国高校最早建立的生物学系之一。学院拥有微生物学国家重点学科，植物学、动物学、遗传学、生物化学与分子生物学均为博士点。毕业生对口生物医药、农业、医检、环保、科研教育等行业。

**标签：** `#生命科学` `#生物学` `#微生物学` `#植物学` `#动物学` `#生物医药`


### 卡片02 · 名师风骨

**摘要：** 从李汝祺到周与良、王义翘，南开生命科学接力传承，开创了中国昆虫遗传学与组织培养技术。

**正文：**
- **李汝祺（1895-1991）**：著名昆虫遗传学家，中国遗传学奠基人之一，长期执教南开，是中国遗传学教学与研究的开创者。
- **萧采藩（1904-1988）**：南开生科重要学者之一，主攻植物形态学与分类学。
- **周与良（1923-2001）**：著名真菌学家，南开生物学重要传承者，推动南开真菌学科建设。
- **尚永丰（1964- ）**：著名生物化学与分子生物学家，中国科学院院士，南开大学生命科学学院教授，专攻表观遗传学与肿瘤分子生物学，2019 年起任南开大学校长。
- **陈佺、刘林**：当代南开生科领军学者，分别主攻细胞生物学与神经科学。

**标签：** `#李汝祺` `#萧采藩` `#周与良` `#尚永丰` `#南开生科`


### 卡片03 · 卓越校友

**摘要：** 南开生科校友遍布学界与生物医药产业，在抗生素、农业、医检等领域开枝散叶。

**正文：**
- **王义翘**（南开生物系早期校友）：美国麻省理工学院（MIT）终身教授、华人生物工程学开拓者之一。
- **尚永丰（1982级）**：中国科学院院士，南开大学校长，主攻肿瘤分子生物学。
- **张新生**（南开生科校友）：中国农业科学院相关所重要学术骨干。
- **青年校友群**：分布在华大基因、药明康德、康龙化成、诺禾致源等头部基因/生物医药企业，从事研发与管理。

**标签：** `#王义翘` `#尚永丰` `#华大基因` `#药明康德` `#诺禾致源`
