# 化学学院 · 


### 卡片01 · 学院名片

**摘要：** 南开化学是中国高校化学学科的一面旗帜，拥有农药化学、离子交换树脂、有机磷化学等多个开创性方向。优势领域涵盖有机化学、无机化学、高分子化学、农药化学、能源材料，毕业生对口制药、新材料、新能源、化工、环保、科研教育等行业。

**标签：** `#化学` `#有机化学` `#农药化学` `#离子交换树脂` `#新能源材料`


### 卡片02 · 名师风骨

**摘要：** 从邱宗岳到周其林，百年南开化学薪火相传，撑起了中国化学的“南开脊梁”。

**正文：**
- **邱宗岳（1890-1975）**：化学系创建人，1921年放弃优厚待遇来南开任教，开设多门近代化学课程，为南开化学奠基。
- **杨石先（1897-1985）**：中科院院士，中国农药化学奠基人，1923年起任教南开，创建我国高校首个元素有机化学研究所。
- **何炳林（1918-2007）**：中科院院士，“离子交换树脂之父”，1956年回国研制出我国第一代离子交换树脂，直接用于原子弹原料提取。
- **陈茹玉（1919-2012）**：中科院院士，有机磷化学家，与何炳林一同回国，开创我国有机磷农药研究，贡献国防与农业。
- **申泮文（1916-2017）**：中科院院士，无机化学奠基人，编写国内首部中文无机化学教材，执教70余年，90多岁仍上讲台。
- **李正名（1931-2021）**：工程院院士，创制我国首个自主知识产权除草剂“单嘧磺隆”，守护粮食安全，设立奖学金回馈南开。
- **周其林**：中科院院士，发现高效手性螺环催化剂，获2019年国家自然科学一等奖，推动手性药物绿色合成。

**标签：** `#邱宗岳` `#杨石先` `#何炳林` `#陈茹玉` `#申泮文` `#李正名` `#周其林`


### 卡片03 · 卓越校友

**摘要：** 南开化学校友遍布学术界与产业界，从“治污院士”到上市公司董事长，在不同领域践行南开精神。

**正文：**
- **张全兴（1960届）**：工程院院士，南京大学教授，开创树脂吸附法治理有毒有机工业废水，被誉为“治污院士”。
- **李正名（1956届硕士，毕业证001号）**：工程院院士，创制绿色农药“单嘧磺隆”，大幅降低农业生产成本。
- **赵国锋**（南开化院教师）：天津久日新材料董事长，推动光引发剂国产化替代，累计投资12亿元带动欠发达地区产业发展。
- **郑保富（2001届）**：上海皓元医药董事长，带领企业深耕药物研发，以科技创新服务医药产业。

**标签：** `#张全兴` `#李正名` `#赵国锋` `#郑保富` `#久日新材` `#皓元医药`


### 卡片04 · 校友捐赠

**摘要：** 化学校友以真金白银反哺母院，设立多项基金支持学科发展与人才培养。

**正文：**
- **李正名**：多次向杨石先奖学金追加捐款50万元，并设立“李正名奖学金”。
- **赵国锋**：2021年捐资3000万元设立“久日新材—南开大学化学学科发展基金”。
- **郑保富**：2025年捐资2000万元设立“皓元医药—南开大学化学学科发展基金”，并受聘南开校董。
- **吕滋立（1985级）**：蓝盾集团创始人，先后捐资1500万元设立“蓝盾基金”，支持学生创业。
- **张曦赜（1991级）**：2019年捐资100万元设立“鸿芹顶级机构访学奖学金”。
- **孙忠杰**：捐款100万元设立永久性“诺未奖学金”。
- **常青藤集团（校友企业）**：捐赠500万元设立“常青藤基金”。
- **化学系94届集体**：毕业20周年捐款10万元。
- **何炳林、陈茹玉夫妇**：将国家一等奖奖金全额捐给南开，创立“何炳林陈茹玉励学金”。

**标签：** `#校友捐赠` `#久日新材` `#皓元医药` `#蓝盾基金` `#化学学科发展基金`


### 卡片05 · 新晋校友都去了哪些企业？

**摘要：** 基于公开信息整理的化学校友集中任职企业清单，供锁定目标、主动搜索和联系校友使用。

| 行业方向 | 典型企业（均有化学校友任职） |
|---------|---------------------------|
| **制药/生物医药** | 皓元医药、药明康德、凯莱英、康龙化成、泰格医药 |
| **新材料/化工** | 久日新材、万华化学、华峰化学、金发科技、蓝盾集团 |
| **新能源/电池** | 宁德时代、比亚迪、亿纬锂能、天赐材料、恩捷股份 |
| **环保/水处理** | 南京大学环境学院（张全兴团队）、中持股份、碧水源 |
