
# 物理科学学院


### 卡片01 · 学院名片

**摘要：** 中国最早物理系之一，百年物理、光学强校。优势方向涵盖物理学、光学、凝聚态物理、理论物理、光电信息，毕业生对口光电、半导体、新能源、芯片、科研、教育及高端制造行业。

**标签：** `#物理学` `#光学` `#凝聚态物理` `#光电信息` `#半导体`


### 卡片02 · 名师风骨

**摘要：** 从饶毓泰到葛墨林，一代代物理学者在南开接力传承，奠定了中国物理学的学术根基。

**正文：**
- **饶毓泰（1891-1968）**：中国现代物理学先驱，南开物理系首任系主任（1922-1930），率先在国内开设近代物理课程，培养了中国第一代物理学人才。
- **顾静徽（1900-1983）**：中国第一位物理学女博士，1931年任南开物理系主任，是国内最早讲授近代物理学、量子力学的女学者之一。
- **吴大猷（1907-2000）**：“中国物理学之父”，在南开任教期间培养出李政道、杨振宁及朱光亚、郭永怀等“两弹一星”元勋。
- **胡刚复（1892-1966）**：中国近代物理学奠基人之一，建国后率先在国内建立光学、理论物理、固体物理等专业方向。
- **沈寿春（1915-1990）**：长期执教南开物理系，在国内率先建立光学专业方向，为母国光等一代代物理人才奠定学术基础。
- **母国光（1931-2012）**：中科院院士，1992-1995年任南开大学校长。在白光光学图像处理领域取得重大突破，编著的《光学》是我国第一部标志水平的基础光学教科书。
- **葛墨林**：中科院院士，长期从事理论物理研究，发现“杨-米尔斯规范场”存在无穷维代数结构，曾获国家自然科学三等奖。

**标签：** `#饶毓泰` `#吴大猷` `#母国光` `#葛墨林` `#物理奠基人`


### 卡片03 · 卓越校友

**摘要：** 南开物理校友遍布“两弹一星”元勋、中科院院士和产业领军者。

**正文：**
- **郭永怀**（1940年代西南联大物理系进修）：“两弹一星”元勋，唯一在原子弹、氢弹和人造卫星三个领域均有开创性成就的科学家。
- **母国光**（1952届）：中科院院士，在白光光学图像处理和信息光学领域取得重大科研成果。
- **孙昌璞**（1992届博士）：中科院院士，提出q变形玻色子概念，构造杨-Baxter方程新型解，为量子信息存储奠定理论基础，2019年获“杰出校友”。
- **王占国**：中科院院士，在半导体材料和凝聚态物理领域贡献卓著。
- **宋玉泉**：中科院院士，在超塑性和塑性加工领域取得重大成果。
- **方国洪**：中国工程院院士，在海洋潮汐和海洋环流领域作出杰出贡献。

**标签：** `#郭永怀` `#孙昌璞` `#两弹一星` `#中科院院士` `#量子信息`


### 卡片04 · 校友捐赠

**摘要：** 校友以真金白银反哺物理学科，累计捐赠超千万元。

**正文：**
- **刘亦方**（1979级）：香港丰联集团总裁，捐赠300万元设立物理学科发展基金，并设“亦方基金”。
- **葛毅与任晓倩夫妇**（1984级）：魔漫相机创始人，捐赠300万元设立物理学科发展基金。
- **匿名校友**：捐赠300万元支持物理学科发展基金。
- **张建军**（1985级）与**李瑞杰**（1985级电子系）：三利谱光电与宝德集团董事长，联合捐赠100万元。
- **刘道志**（1981级）与**张忠民**夫妇（1982级）：山蓝资本与乐奥医疗创始人，捐赠50万元设立“忠道奖学金”。
- **李中泽**（1986级电子系）：盛帆集团董事长，捐赠1000万元支持学校发展建设。
- **物理系88级校友集体**：物理学科创建100周年之际，众筹募集334,246元支持学院建设。

**标签：** `#校友捐赠` `#物理学科发展基金` `#刘亦方` `#李中泽`
