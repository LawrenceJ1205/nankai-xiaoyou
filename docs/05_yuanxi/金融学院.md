# 金融学院 · 


### 卡片01 · 学院名片

**摘要：** 中国金融学科的主要开创地之一，钱荣堃创办我国首个国际金融博士点，刘茂山开创中国精算教育先河。优势方向涵盖国际金融、货币银行、保险精算、金融工程、数字金融，毕业生对口银行、证券、基金、保险、资管、金融科技等行业。

**标签：** `#金融` `#国际金融` `#保险精算` `#金融工程` `#数字金融`


### 卡片02 · 名师风骨

**摘要：** 从钱荣堃到陈雨露，南开金融名师辈出，奠定了中国金融学科的教育体系与国际接轨的格局。

**正文：**
- **钱荣堃（1917-2003）**：中国金融学科主要奠基人，被誉为“中国的MBA之父”，创办我国第一个国际金融硕士点和博士点，主编《国际金融》经典教材。
- **刘茂山（1933- ）**：中国金融学科终身成就奖获得者，南开保险、精算学科创始人，1988年开创中国精算教育先河，与北美精算师学会接轨。
- **滕维藻（1917-2008）**：著名经济学家，南开经济学院首任院长，毕生从事世界经济与国际金融研究。
- **王继祖（1928-2012）**：著名国际金融学家，在国际收支、汇率理论领域成就卓著。
- **马君潞（1954-2014）**：著名金融学家，长期从事国际金融、货币理论与政策研究。
- **梁琪**：南开金融学院教授、经济学院院长，长期从事宏观金融、风险管理研究。
- **陈雨露**：南开大学校长、金融学院教授，曾任中国人民银行副行长，国家自然科学基金重大项目负责人。

**标签：** `#钱荣堃` `#刘茂山` `#滕维藻` `#陈雨露` `#国际金融` `#精算`


### 卡片03 · 卓越校友

**摘要：** 南开金融校友遍布资本市场、监管机构和学术界，是中国金融业的中坚力量。

**正文：**
- **钱荣堃（1944届南开经济所硕士）**：创办我国第一个国际金融博士点，被誉为“中国的MBA之父”。
- **周海冰（1988级数学、金融双学位）**：乾通科技董事长，2016年与侯莹校友共同捐赠1亿元。
- **盛希泰（1990级金融硕士）**：洪泰基金创始人，曾任华泰联合证券董事长。
- **高凤勇（金融校友）**：力鼎资本创始合伙人，基金管理规模超200亿元，发起“八里台金融论坛”。
- **于瑾（1984级国际金融本科）**：对外经济贸易大学教授，被追授“全国优秀教师”。
- **范小云**：南开金融学院院长，国务院特贴专家，牵头创设“钱荣堃班”。

**标签：** `#盛希泰` `#高凤勇` `#范小云` `#洪泰基金` `#力鼎资本`


### 卡片04 · 校友捐赠

**摘要：** 金融校友以雄厚资本反哺母院，设立基金推动金融教育持续发展。

**正文：**
- **周海冰与侯莹校友**：2016年共同捐赠1亿元人民币，其中5000万元设立“智德基金”，支持金融学院等五个院系。
- **钱荣堃金融教育基金**：2023年由南开金融校友发起，首期规模1000万元，用于推动南开金融教育事业发展。同年设立“钱荣堃班”。
- **瑾基金**：2019年，为纪念于瑾校友，师生校友捐资2000万元设立，用于奖励师德高尚的教师和优秀学子。
- **深圳悟空投资管理有限公司**：在金融学院成立大会上捐赠300万元，设立“熵控网络”教席教授。
- **詹先华（1983级金融专业）**：在金融学院成立大会上捐赠10万美元。
- **刘禹东**：钱荣堃金融教育基金主要发起人，持续为师资引进和学科建设作出贡献。
- **北京乾元联合投资等校友企业**：捐赠100万元，支持建立互联网金融实验室。

**标签：** `#校友捐赠` `#钱荣堃金融教育基金` `#瑾基金` `#悟空投资`


### 卡片05 · 新晋校友都去了哪些企业？

**摘要：** 基于公开信息整理的金融校友集中任职企业清单，供锁定目标、主动搜索和联系校友使用。

| 行业方向 | 典型企业（均有金融校友任职） |
|---------|---------------------------|
| **券商/投行** | 中金公司、中信证券、华泰联合、国泰君安、海通证券 |
| **公募基金** | 易方达、华夏基金、嘉实基金、南方基金、富国基金 |
| **私募/PE/VC** | 洪泰基金、力鼎资本、同创伟业、优山资本、君和资本 |
| **银行** | 工农中建交总行、招商银行、兴业银行、浦发银行 |
| **保险/资管** | 中国人寿、平安集团、泰康保险、人保资产 |
| **金融科技** | 蚂蚁集团、腾讯金融、京东科技、度小满 |

**使用建议：** 锁定目标企业 → 打开“找校友”按企业名称搜索 → 联系在该企业任职的金融校友。

**标签：** `#校友去向` `#券商` `#基金` `#银行` `#保险` `#金融科技`
