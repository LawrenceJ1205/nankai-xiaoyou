# 🔯 哲学院 ·


### 卡片01 · 学院名片

**摘要：** 南开哲学学科历史悠久，是国内"哲学五校"之一。前身可追溯至 1919 年南开大学建校初的哲学系，先后培养出"逻辑学家温公颐"、"美学大师李泽厚"等标志性学者。2003 年正式复建哲学院。优势方向涵盖马克思主义哲学、中国哲学、外国哲学、伦理学、科技哲学、逻辑学、美学。毕业生对口高校、党政、研究、出版、咨询、文化等行业。

**标签：** `#哲学` `#马克思主义哲学` `#中国哲学` `#伦理学` `#逻辑学` `#美学`


### 卡片02 · 名师风骨

**摘要：** 从温公颐到李泽厚、陈晏清，南开哲学薪火相传，在中国哲学、马克思主义哲学、伦理学领域形成"南开学派"。

**正文：**
- **温公颐（1904-1999）**：著名逻辑学家，南开大学哲学学科重要奠基人之一，主攻中国逻辑史与符号逻辑。
- **李泽厚（1954级哲学系）**：著名哲学家、美学家、中国现代思想界代表人物之一，著有《中国古代思想史论》、《美的历程》。
- **陈晏清（1935-2019）**：著名马克思主义哲学家，南开大学原副校长，主攻辩证唯物主义、社会哲学，推动建立"南开—北大马克思主义哲学学派"。
- **王树人（1936- ）**：著名哲学家，长期执教南开，专攻中国传统哲学与德国古典哲学。
- **阎孟伟（1958- ）**：南开哲学院教授，长期从事马克思主义哲学与社会哲学研究。
- **李翔海（1962- ）**：南开哲学院院长（多届），主攻中国哲学与中西哲学比较。
- **吴克峰、刘东**：南开哲学院当代主政研究方向的中坚学者。

**标签：** `#温公颐` `#李泽厚` `#陈晏清` `#王树人` `#南开哲学`


### 卡片03 · 卓越校友

**摘要：** 南开哲学校友遍布学界、政界与文化界，在哲学、思想史、文化研究等领域形成"南开哲学群体"。

**正文：**
- **李泽厚（1954级哲学系本科）**：著名哲学家、美学家，是中国当代最具影响力的人文思想家之一。
- **陶东风（1990年代校友）**：著名文艺理论学者，曾任首都师范大学教授，公共文化研究方向代表人物之一。
- **韩水法（南开哲学系校友）**：北京大学哲学系教授，主攻德国哲学与政治哲学。
- **夏莹（1990级校友）**：南开大学哲学院教授，当代马克思主义哲学新生代代表学者之一。

**标签：** `#李泽厚` `#陶东风` `#韩水法` `#夏莹` `#公共文化`


### 卡片04 · 校友捐赠

**摘要：** 哲学学院获得校友与社会捐赠支持哲学教育、青年学者培养与学术活动。

**正文：**
- **校友基金（哲学系 86 级）**：纪念入学 30 周年，集体捐赠设立"哲学新声基金"，鼓励青年学者原创研究。
- **匿名校友**：捐赠支持"南开哲学青年访问计划"，接待校内外哲学青年学者短期访问研究。
- **校友企业（出版集团）**：捐赠支持学院"哲学经典文库"翻译项目。

**标签：** `#校友捐赠` `#南开哲学` `#哲学新声基金`
