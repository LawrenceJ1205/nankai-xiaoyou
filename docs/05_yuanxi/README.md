## 🤝 院系底座 · 认领机制（面向校友企业）

> **先说一个判断**：对"要找工作"的校友来说，一个入口（[💼 允能南开人](07_yunneng/README.md)）就够了——不需要再绕一道"院系介绍"。
> 那么，还有谁需要来"小友"看院系？**这个问题，我们留给愿意把"小友"做大的校友企业。**

| 项 | 规则 |
|---|---|
| **谁来认领** | 校友企业（可认领本院系，也可认领相关院系） |
| **认领后做什么** | 该院系页由认领企业**接手内容**：本院系校友企业名录 + 可提供的实习/校招岗位 + 可值班的校友 |
| **认领后得到什么** | 页首署名"由 ○○ 校友企业支持"；岗位直通 [💼 允能南开人](07_yunneng/README.md)；掌门人可进 [🧭 新开吧](07_yunneng/xinkaiba/README.md) 值守与讲课 |
| **未认领的院系** | 保持目录占位，**不做内容投入**——不写没有把握的院系介绍 |

> 📌 一句话：院系页**不做"介绍院系"的活，做"本院系 → 校友企业 → 岗位与导师"的活**；有企业认领才开张。
