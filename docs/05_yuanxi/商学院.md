# 📊 商学院 ·


### 卡片01 · 学院名片

**摘要：** 国内管理学教育的"南开支柱"。南开 MBA 起源于 1983 年，是中国首批 MBA 试点院校（1991 年）之一。拥有中国管理学界的"南开学派"代表人物，国际上通过 **AACSB / EQUIS / AMBA** 三大认证，是国内少数通过三冠认证的商学院之一。学科涵盖企业管理、会计、财务管理、市场营销、人力资源、信息管理。毕业生对口管理咨询、投资银行、企业战略管理、市场营销、互联网产品、HR 等行业。

**标签：** `#商学院` `#MBA` `#AACSB` `#EQUIS` `#管理学` `#企业管理`


### 卡片02 · 名师风骨

**摘要：** 从陈炳富到张玉利、李维安，南开管理学薪火相传，在中国管理学界有"南开学派"之称。物美集团创始人**张文中**（1985 级管理系硕士）即出自这一脉。

**正文：**
- **陈炳富（1923-2017）**：著名管理学家，南开大学企业管理学科奠基人，被誉为"中国 MBA 教育开拓者"——物美集团创始人**张文中**（1985 级管理系硕士）即出其门下。
- **郑明琳**：南开管理学前辈学者。
- **张玉利（1954- ）**：著名创业管理学者，南开大学原副校长，中国创业研究领军学者之一，主攻创业管理与中小企业成长。
- **李维安（1956- ）**：著名公司治理学者，南开讲席教授，中国公司治理研究院创始人。
- **白长虹（1965- ）**：南开商学院教授，主攻服务管理与市场营销。
- **许晖、林润辉、崔勋** 等：当代南开商学院中坚学者。

**标签：** `#陈炳富` `#张玉利` `#李维安` `#白长虹` `#MBA` `#南开管理学派`


### 卡片03 · 卓越校友

**摘要：** 南开商学院校友遍布上市公司管理层、创业生态、咨询与投资领域，是商界"南开力量"的代表。

**正文：**
- **李罗力**（南开经济学博士）：南开经济校友会会长，综合开发研究院（中国·深圳）主任。
- **张文中（南开 1979 级数学系本科毕业；1985 年回南开攻读管理系硕士，师从管理学奠基人陈炳富教授）**：物美集团创始人，多点 Dmall 董事长，南开校友企业家联谊会主席。
- **周海冰（南开数学、金融双学位）**：乾通科技董事长，捐赠 1 亿元支持南开建设。
- **袁岳（南开社会学硕士）**：零点有数董事长，咨询行业创业代表。
- **创业校友群**：分布在消费品、SaaS、企业服务、医疗器械、产业互联网等赛道，多位入选福布斯 / 胡润 U40。

**标签：** `#张文中` `#周海冰` `#袁岳` `#李罗力` `#咨询`


### 卡片04 · 校友捐赠

**摘要：** 商学院获得校友与校友企业的大量捐赠，涵盖学科建设、学生培养、师资引进。

**正文：**
- **周海冰与侯莹校友**：2016 年共同捐赠 1 亿元人民币，其中 5000 万元设立"智德基金"，覆盖商学院等 5 个院系。
- **张文中**：多次捐赠支持南开校友企业家联谊会与商学学科建设。
- **深圳校友会 / 11 位校友代表**：2019 年南开百年校庆期间，捐赠 1.8 亿元，其中相当部分用于商学院。
- **袁岳校友**：长期支持商学院"创业管理"研究方向。
- **匿名企业家校友**：在 2019 年南开校友企业家联谊会成立大会上，捐赠 1.72 亿元支持数学、金融、AI、管理等学科。

**标签：** `#校友捐赠` `#智德基金` `#周海冰` `#张文中` `#匿名校友 1.72 亿`

### 卡片06 · 找校友联络节点

### 卡片07 · 允能南开人（商学院入口）

**摘要：** 允能南开人是校友企业发布真实用工需求的平台。我们将鼓励并请求校友企业人事部按规范格式实时更新岗位信息，确保时效性。

| 操作路径 | 说明 |
|---------|------|
| 首页 → 允能南开人 → 筛选"管理/咨询/投行/产品" | 所有岗位由校友企业自主上架 |
| 若暂无新岗位，显示"暂无新鲜岗位，建议先找人" | 诚实展示，引导用户先建立人脉 |
| MBA/EMBA 内推提醒 | MBA 院校友是企业内推最优来源，建议同班同学共享岗位 |

**标签：** `#允能南开人` `#校友企业` `#岗位投递` `#商学院`


### 卡片08 · 商院校友求职行动清单
