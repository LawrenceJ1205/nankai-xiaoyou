# 💼 允能南开人

> **一句话定位**：南开人从校园走向社会的**接驳站**——一头连着**校友企业的真实岗位池**，一头连着**在校生与毕业 0–3 年的年轻校友**；中间垫着**校友亲口留下的三份底稿**（[校友 · 致在校生寄语](07_yunneng/校友·致在校生寄语.md) · [校友 · 走进社会的坑与悟](07_yunneng/校友·走进社会的坑与悟.md) · [校友推荐书单](07_yunneng/校友推荐书单.md)）与一个**排班值守的** [🧭 新开吧](07_yunneng/xinkaiba/README.md)，把“学校没教、社会先考”的那门课，提前补上。
>
> 📖 **名字的来历**：取自南开校训「**允公允能，日新月异**」。**允能**，是把本事练到「机会来了接得住」——这里给的就是**练本事、拿机会**的地方。与 [🏆 骄人南开校友企业 · 允公南开人](06_jiaoren/README.md) 互为问答：**先「允能」（练本事），后「允公」（担责任）**。
>
> **板块性质**：**小友的主力板块**——为其他主力板块提供「就业出口」，也是校友职场经验的**中转站**：**出岗位、出经验、出书单、出带路人**。
