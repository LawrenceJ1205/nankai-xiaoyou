## 💡 我要提问（模板）

```
新开吧 · 我的提问

1. 我的身份（年级 / 学院 / 专业）：
2. 我现在最纠结的一件事（一句话）：
3. 我试过什么、卡在哪：
4. 我想从学长这里得到什么：
   □ 行业信息  □ 简历/面试建议  □ 选择框架  □ 心理准备  □ 想认识某类校友
5. 是否愿意在「新开吧」公开提问（隐去个人信息后）：□是 □否

提交渠道：允能南开人微信群 + 小鹅通专题页讨论区
```

> 📌 **提问也会沉淀**：每个被回应的问题，7 天内整理成"一问一答"卡片永久可检索——和 [🌟 淘知吧](03_xinzhi/taozhi/README.md) 同一套机制。

## 🛡️ 红线（在校生保护）

- **不收集**身份证号 / 学号 / 家庭信息等敏感字段；简历门诊一律先脱敏
- **不收费**：任何形式的"付费内推""保 offer"都不是本吧提供的
- **不承诺**：值守校友不给"保录 / 包过"承诺，只给信息与判断
- **不代投**：不把简历转投给非校友企业；投递一律由学生本人发出
- **不晒人**：不公开在校生的真实身份与提问原文（脱敏后才沉淀）
