# 📚 捐赠图书

> **所属板块**：[❤️ 南开慈善公益](09_cishan/README.md)　｜　**本页是「公益项目对接」项下的专题页**
>
> **一句话定位**：从明确需求方（图书馆／机构）的要求出发，登记一份可被对接的捐书意向——让书去到真正需要它的地方。
>
> **信息截至**：2026-11-21　｜　**更新方式**：意向登记 → 自行对接 → 自行交付（见第三节）
>
> **⚪ 口径**：本板块**仅做项目发布与展示**，实际捐赠在学校及各地校友会完成。本页与配套表单**只登记意向**——不收款、不代收图书、不作图书估值、不承诺或担保对接结果。

## 一、为什么单设这一页

**🔵 活动缘起（主理人定调）**：关注慈善捐书的校友们，“南开小友”的捐书活动将从各个校友关注或希望捐赠图书的图书馆认可我们的捐书开始，也就是我们将从明确需求方的要求开始，无论是南开图书馆还是贫困地区的图书馆。校友们有自己的渠道得知具体图书馆的需求后，也可以在“小友”平台和大家分享。

站内已有两处与「书」有关的公开记录：

- [📚 读书汇](02_jiayuan/读书汇/README.md) 把 14 本书做成「书籍导览」，回答的是「读什么、怎么读」；
- [🎬 南开上海校友会建会百年暨复会三十周年](08_xiaoyouhui/新闻花絮/2026-10-24·南开上海校友会建会百年暨复会三十周年.md) 的通稿里，记有校友捐出 1926 年创刊的首期《南中周刊》等史料捐赠。

**⚪ 归纳**：一头是图书馆／机构的具体需求，一头是校友愿意拿出的书，中间缺的是一份可查的意向清单。本页只收拢这一处信息差——**小友不办捐书活动、不设书库、不经手图书**。

## 二、什么样的书适合登记

| 适合登记 | 暂不建议登记 |
| --- | --- |
| 正版、有 ISBN、品相完好的学术专著与教材 | 盗版、影印不清或来源不明的书 |
| 文学、人文、少儿读物与工具书 | 严重污损、缺页、霉变，或不宜再流通的书 |
| 南开史料、校史与校友著作（含签名本、题词本） | 含未清理的个人隐私批注、信件或证件的书 |
| 内容与南开、「公能」精神或校友行业相关的书 | 涉密资料、内部刊物、尚未公开的材料 |
| 批量复本（教材、专著、活动用书） | 已过时效且无史料价值的中小学教辅、过期法规汇编 |

> **⚪ 说明**：上表是**填报前的自查**，不是接收标准；是否接收、接收范围与数量，一律由受赠方自行判断。

## 三、四步走（谁做什么）

| 步 | 动作 | 谁做 |
| --- | --- | --- |
| 1 | 填写「捐赠图书意向登记」，写清接受捐赠的图书馆／机构名、所需图书大类、图书名及出版年份与交付方式 | 捐赠人 |
| 2 | 自行联系意向受赠方，确认是否接收、接收范围、时间与方式 | 捐赠人 |
| 3 | 自行寄送或送达，运费、包装与交付安排由双方自行商定 | 捐赠人 |
| 4 | 如需在站内展示，把**可公开披露**的信息回传本板块（可选） | 捐赠人 → 板块主理 |

**⚪ 责任自担**：任何主体（含高校／院系师生、校友及其他参与方）若自行承接本页所涉工作，其投入、后果与责任均由该主体自行承担；南开小友不参与、不担保、不兜底。本材料不构成对上述主体的邀约、指派或建议。
