## 💎 师长名义慈善（首期示例）

> 📝 **首期状态**：与南开校友总会洽谈中——计划引入"张伯苓教育基金""严范孙助学项目""周恩来奖学金"等历史悠久项目。

| 项目 | 师长 | 用途 |

| 严范孙助学项目 | 严范孙先生 | 鼓励学生赴西部支教 |
| 周恩来奖学金 | 周恩来总理 | 奖励品学兼优 + 服务社会的学生 |
| 杨石先化学奖学金 | 杨石先先生 | 资助化学学科本科生深造 |

## 🛤️ 重走西南联大之路

> **联大精神**：1937 年南开与北大、清华南迁昆明，组成国立西南联合大学，在战火中坚守 8 年，培养出 2 位诺贝尔奖得主 + 170 余位两院院士。

### 首期路线（计划）

| 路线 | 时长 | 关键节点 |
|---|---|---|
| **长沙临时大学旧址** | 1 天 | 湖南长沙 · 圣经学院 |
| **蒙自南湖诗社** | 2 天 | 云南蒙自 · 西南联大蒙自分校 |
| **昆明西南联大旧址** | 3 天 | 云南师范大学 · 国立西南联合大学旧址 |

### 报名方式

> 🚧 首期路线将在 2026 年 11 月（与"南开 100 年·返校"前后）启动——届时通过 [**🌐 南开公社**]](02_jiayuan/gongshe/README.md) 报名。

## 🎨 数字藏品（探索中）

> **初步设想**：以南开知名慈善捐赠项目（如张伯苓教育基金、杨石先化学奖学金）的**历史档案 + 信物原件**为原型，发行限量数字藏品，传播南开公益精神。

| 候选原型 | 来源 | 状态 |
|---|---|---|
| 张伯苓教育基金·首期纪念章 | 校史馆档案 | 概念设计 |
| 杨石先化学奖学金·获奖证书 | 化学学院档案 | 概念设计 |
| 周恩来奖学金·南开中学时期成绩单 | 档案馆 | 资料整理中 |

> **重要**：数字藏品**不构成任何金融属性**，仅作为公益传播与文化传承载体。
