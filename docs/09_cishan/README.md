# ❤️ 南开慈善公益

> **一句话定位**：以南开精神为底色，汇聚校友公益力量——**重走西南联大之路、师长名义捐赠、数字藏品传承**。
>
> **说明**：本板块**仅做项目发布与展示**，实际捐赠在学校及各地校友会完成。
>
> **隶属关系**：本板块是**外延服务板块**——它体现南开人的精神底色，本身不隶属于任何主力板块。

## 🛤️ 重走西南联大之路

> **联大精神**：1937 年南开与北大、清华南迁昆明，组成国立西南联合大学，在战火中坚守 8 年，培养出 2 位诺贝尔奖得主 + 170 余位两院院士。

### 首期路线（计划）

| 路线 | 时长 | 关键节点 |
|---|---|---|
| **长沙临时大学旧址** | 1 天 | 湖南长沙 · 圣经学院 |
| **蒙自南湖诗社** | 2 天 | 云南蒙自 · 西南联大蒙自分校 |
| **昆明西南联大旧址** | 3 天 | 云南师范大学 · 国立西南联合大学旧址 |

### 报名方式

> 🚧 首期路线将在 2026 年 11 月（与“南开 100 年·返校”前后）启动——届时通过 [**🌐 南开公社**](02_jiayuan/gongshe/README.md) 报名。

## 🎨 数字藏品（探索中）

> **初步设想**：以南开知名慈善捐赠项目（如张伯苓教育基金、杨石先化学奖学金）的**历史档案 + 信物原件**为原型，发行限量数字藏品，传播南开公益精神。

| 候选原型 | 来源 | 状态 |
|---|---|---|
| 张伯苓教育基金·首期纪念章 | 校史馆档案 | 概念设计 |
| 杨石先化学奖学金·获奖证书 | 化学学院档案 | 概念设计 |
| 周恩来奖学金·南开中学时期成绩单 | 档案馆 | 资料整理中 |

> **重要**：数字藏品**不构成任何金融属性**，仅作为公益传播与文化传承载体。

## ❤️ 骄人校友企业的社会捐赠（企业侧 · 面向社会）

> **口径**：本节只收**面向社会**（家乡与教育 / 公共卫生与应急 / 基层医疗 / 长期公益 / 乡村振兴）的捐赠与公益行动，且**只收有公开来源可查**的记录；**面向母校**的捐赠另见 [🏆 骄人南开校友企业 · ❤️ 回馈南开 · 回馈社会](06_jiaoren/回馈南开·回馈社会.md)。
>
> **意义**：这些不是“企业的公关动作”，而是**南开「公能」精神在企业层面的落地样本**——与上文“以南开师长名义的慈善捐赠”“重走西南联大之路”同属一条精神脉络。本板块将陆续把它们做成**案例卡**，供校友企业与各地校友会对接参考。
>
> **⚠️ 口径分列（沿用 06 板块第 5 条铁律）**：伯特利属**联谊会生态圈成员企业**（创始团队非南开校友，系南开系资本被投），此处按其公开公益记录收录，**不称「校友企业」**。
