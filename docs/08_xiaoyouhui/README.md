# 💬 各地校友会

> **一句话定位**：无论您身在何处，都能**找到组织、参与到当地的校友活动中**，感受南开大家庭的温暖。
>
> **隶属关系**：本板块是**外延服务板块**——它为三核心板块提供"在地化连接"，本身不隶属于任何核心板块。

## 📍 校友会名录（首期 3 个核心节点）

### 🌐 南开北京校友会

> **规模**：南开最大地方校友会之一，理事会 15 人 + 跨行业分会 8 个

| 项 | 内容 |
|---|---|
| **覆盖城市** | 北京 |
| **活跃分会** | 经济与政策 / 金融与投资 / 数学与量化 / 物理 / 化学 / MBA·EMBA / 互联网创业 / 法律 |
| **特色活动** | 年度大讲堂、迎新晚会、跨分会联合论坛 |
| **加入方式** | 公众号「南开北京校友会」→「我要加入」 |

### 💎 南开深圳校友会

> **规模**：改革开放后崛起的南开人聚集地，硬科技 + 创业氛围浓

| 项 | 内容 |
|---|---|
| **覆盖城市** | 深圳 + 粤港澳大湾区 |
| **活跃分会** | 硬科技 / 金融投资 / 经济与管理 / 物理校友群 |
| **特色活动** | 深圳湾论坛、湾区内互访、年度粤港澳校友联合 |
| **加入方式** | 联系江联（主理人）→ 内推入群 |

### 🔍 未单独建群的城市 + 海外校友

> 📝 **引导说明（按 v2.2 原则）**：本平台**不在校友会板块收录未单独建群城市的校方平台入口**——校友需要什么自己能搜到，本板块只做"已建群的当地校友会"。
>
> 对未单独建群城市的校友：
> - **同城找组织**：联系主理人江联，或在各城市**本地校友群**互找
> - **海外校友**：联系最近的中国驻外使领馆 + 海外校友志愿者
> - **筹建联络站**：满 5 人即可申请筹建群组，由江联亲自协助启动
> - **大型活动**：跨城校友活动在 [🎓 不一样的回南开](01_huixue/README.md) 板块集中召集
