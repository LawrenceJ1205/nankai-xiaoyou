### 四地校友会为什么值得一个专区

四地校友会在做的三件事，正是一张校友网络最要紧的三根线：

- **连接校友与学校**——新开湖论坛白承铭副校长到场讲学科建设；蓝盾创新创业成果评奖大会（深圳校友会出资）**在母校举行**；南开书屋落进湖南两县
- **连接校友企业与学校**——四场新开湖主旨演讲（新药体系、北斗、算力、存储）全部出自校友企业家与母校学者的真实产业
- **连接校友与校友会**——北京迎新会「校友会就是你们在北京的家」；深圳季度会 150 余位理事到场、现场捐款 268 万；京沪深三会会长同台
