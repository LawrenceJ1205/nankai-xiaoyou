# 💬 各地校友会

> **一句话定位**：无论您身在何处，都能**找到组织、参与到当地的校友活动中**，感受南开大家庭的温暖。

> **隶属关系**：本板块是**外延服务板块**——它为主力板块提供"在地化连接"，本身不隶属于任何主力板块。

### 🔍 未单独建群的城市 + 海外校友

> 📝 **引导说明（按 v2.2 原则）**：本平台**不在校友会板块收录未单独建群城市的校方平台入口**——校友需要什么自己能搜到，本板块只做"已建群的当地校友会"。
>
> 对未单独建群城市的校友：
> - **同城找组织**：联系主理人江联，或在各城市**本地校友群**互找
> - **海外校友**：联系最近的中国驻外使领馆 + 海外校友志愿者
> - **筹建联络站**：满 5 人即可申请筹建群组，由江联亲自协助启动
> - **大型活动**：跨城校友活动在 [🎓 不一样的回南开](01_huixue/README.md) 板块集中召集
