## 这里记什么，不记什么

| 收 | 不收 |

| 各地校友会的**迎新、年会、会庆、论坛、社团纳新**等已办活动 | 尚未举办的活动预告（走 [📅 活动日历](08_xiaoyouhui/README.md) 与 [🎂 107 周年校庆 · 各地校友会活动播报](02_jiayuan/gongshe/107周年校庆·各地校友会活动.md)） |

## ✍️ 怎么报一条

1. 各地校友会秘书处、或现场校友，把**公众号推文链接**（或文字稿）发给板块主理；
2. 主理按上表口径编录成一页，**只写事实**，评价另置「编者按」并标明；
3. 页末编者注列：人名校正、笔误存目、未收录内容（图片 / 二维码 / 报名表）。

> 一条花絮的篇幅控制在**一屏半**以内：一分钟看完的表 + 三段话，多的留给原文。
