## 🧩 建群机制（半自动，可扩）

```
校友填表（选城市 + 选项目 + 是否愿当召集人）
        ↓
金数据 webhook → 家园版主
        ↓
① 同城同项目满 10 人 → 版主建群
② 未满 10 人 → 进"待建池"，凑够即开
③ 有召集人 → 召集人当群主，版主只监管
        ↓
群二维码回填到本页 → 后来者自助扫码入群
```

> **为什么不自动建群**：微信/飞书都不允许外部应用自动建群、自动拉人（详见 `outputs/南友家园·兴趣小组一键建群·落地可行性评估.md`）。  
> 采用 **「群活码 + 人工邀请」** 半自动方案，是 99% 社群的通行做法。

## 📝 报名字段（每项一张专属表）

**通用 12 项**：姓名 / 手机号 / 微信号 / 南开经历 / 所属学院 / **常住城市** / 所在片区 / 方便参与的时间 / **是否愿当召集人** / 可提供的场地资源 / 想说的话 / 联络授权

**专项 5 项**（各表不同）：

| 小组        | 专项字段                                       |
| --------- | ------------------------------------------ |
| 🏃 慢跑     | 配速区间 / 单次距离 / 常跑地点 / 赛事经验 / 期望形式           |
| 🖌️ 书法·绘画 | 主项（毛笔·硬笔·篆刻·绘画）/ 书体偏好 / 水平年限 / 能否授课 / 期望形式 |
| 🏓 乒乓球    | 水平自评 / 握拍 / 常用打法 / 常用场地 / 期望形式             |
| 🏸 羽毛球    | 水平自评 / 单双打偏好 / 每周次数 / 常用场地 / 期望形式          |

> `建群状态 / 入群时间 / 群主` 三个字段**不进表单**，是后台运营字段。
