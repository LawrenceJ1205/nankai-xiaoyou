# 💼 专业南开人

> **一句话定位**：把「校友」处成「同行」——**一项专业 × 跨地区 = 一群南开人**。法律、理财、财务……无论您深耕哪个专业，都能在这里发起或加入同专业的南开人交流群。

> **隶属关系**：← 隶属于 [🔍 我的南开家园](02_jiayuan/README.md) 板块

## 🎯 为什么要有「专业南开人」

兴趣小组按**城市**建群（一项活动 × 一座城市）；专业南开人按**专业**建群（一项专业 × 跨地区）——

| 维度 | ✨ 兴趣小组 | 💼 专业南开人 |
|---|---|---|
| 分群依据 | 城市（就近约练） | **专业领域**（跨地区同行） |
| 交流内容 | 活动 · 切磋 · 约练 | **专业问题 · 实务经验 · 行业动态** |
| 建群逻辑 | 同城同项目 ≥ 10 人 | **同专业 ≥ 10 人**（不限城市） |

> 两个栏目互补：兴趣小组让校友「把同学处成邻居」，专业南开人让校友「把同学处成同行」。

## 🧩 建群机制（半自动，可扩）

```
校友填表（选专业领域 + 填具体题目 + 选发起人/加入者）
        ↓
金数据 webhook → 家园版主
        ↓
① 同专业满 10 人 → 版主建群（不限城市）
② 未满 10 人 → 进"待建池"，凑够即开
③ 有发起人 → 发起人当召集人（群主），版主只监管
        ↓
群二维码回填到本页 → 后来者自助扫码入群
```

> **为什么不自动建群**：与兴趣小组同理——微信／飞书不允许外部应用自动建群、自动拉人。采用 **「群活码 + 人工邀请」** 半自动方案。

## 📝 报名入口与字段

👉 [**填表报名 · 专业南开人（发起或加入）**](https://twpitpbt.jsjform.com/f/TaiNOa)

**通用 8 项**：姓名 / 手机号 / 微信号 / 南开经历（年级 + 学院）/ 常住城市 / **想发起或加入的专业领域**（法律 · 理财 · 财务 · 税务 · 金融投资 · 医疗健康 · 教育与升学 · 信息技术与 AI · 建筑与地产 · 文化传媒 · 人力资源 · 其他）/ **具体专业题目**（细分方向，如「法律—公司合规」）/ **申请身份**（发起人 / 加入者 / 先聊聊看）

**专业 6 项**：当前职业身份 / 从业年限 / 领域专长自述（100 字内）/ 最希望交流的话题 / 可为群提供的资源 / 想说的话

**授权 1 项**：联络授权（同意版主联系并邀请入群）

> `建群状态 / 入群时间 / 召集人` 三个字段**不进表单**，是后台运营字段。
