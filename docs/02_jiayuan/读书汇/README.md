# 📖 读书汇

> **一句话定位**：南开人的人文地平线——与「我的南开故事」并肩的另一条线：**故事记的是“你的南开”，读书汇记的是“你读过的书、以及书里的你在想什么”。**

> **隶属关系**：← 本栏目隶属于 **🔍 [我的南开家园](02_jiayuan/README.md)** 板块（六大主力板块之一）。
> **与「我的南开故事」的分工**：故事是 500 字、写校园记忆；读书汇是 **1000 字以内、一本一投**，写书与人的相互照亮。

---

## 🎯 这里收什么？

| 项 | 说明 |
|---|---|
| **篇幅** | **1000 字以内**（比“我的南开故事”的 500 字放宽一倍——书这件事，需要多说两句） |
| **一本一投** | 一次投一本；读完一本投一本，投稿次数不限 |
| **体裁** | 读后感 / 书里的一句话 ＋ 你的故事 / 这本书改变了你哪一点 |
| **不必是书评** | 不用评价好坏、不用总结全书；写“它让你想起了什么”就够 |
| **不收** | 摘抄合集、AI 代写的通稿、带推广链接的书商稿、未授权的他人稿件 |

---

## ✍️ 怎么写（1000 字模板）

```
读书汇 · 读后感（1000 字以内）

1. 我的南开身份：届别 / 学院 / 现职（也可匿名）
2. 书名 ＋ 作者
3. 为什么是这本书（什么时候、什么处境下读到的，100 字以内）
4. 书里最打动我的一段 / 一句（引文 ＋ 出处，200 字以内）
5. 它改变了我哪一点（400 字以内）
6. 一句话推荐给谁读（100 字以内）
```
