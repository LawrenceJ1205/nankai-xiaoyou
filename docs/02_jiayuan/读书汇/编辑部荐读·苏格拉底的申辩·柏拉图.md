## 一、书档

| 项 | 内容 |
|---|---|

| 作者 | 柏拉图（Plato，约公元前 427–前 347，古希腊哲学家，苏格拉底的弟子） |
| 记录的事件 | 公元前 399 年，苏格拉底（公元前 469–前 399）在雅典法庭上受审时的自我辩护——最终被判死刑 |
| 一句话定位 | 西方哲学的奠基文献之一——一个人**面对死刑，为「省察的人生」辩护** |

## 二、为什么收进读书汇

⚪ 编辑部说明（应主理人提议收录，非校友推荐口径）：

读书汇的副标题是「南开人的人文地平线」。编辑部荐读书架立的「想清楚」三本中，这一本是**源头**：《思考，快与慢》讲想不清楚的心理机制，《穷查理宝典》给想清楚的工具箱，而《申辩》回答的是更根本的一问——**凭什么要一辈子想清楚？**苏格拉底用性命作答。

## 三、全书框架（编者整理）

⚪ 以下为编者依据原书通行译本公开内容做的结构化整理，供快速把握骨架。

### 1. 两条罪名与一层旧怨

雅典人梅勒图斯等三人起诉苏格拉底：**不敬城邦之神、引进新神、败坏青年**。但申辩里真正的对手是盘踞多年的**舆论旧怨**——喜剧舞台上被丑化的「智者苏格拉底」形象。苏格拉底开篇即言：要清除的不是原告，而是众人耳中多年积下的偏见。

### 2. 「无知之知」：神谕的真义

德尔斐神谕说**「没有人比苏格拉底更智慧」**。苏格拉底困惑之下四处拜访以智慧著称的政客、诗人、工匠，逐一对话后悟出神谕的真义：**他比别人聪明之处，仅仅在于——他知道自己不知道，而别人不知道自己不知道。**这就是著名的「无知之知」。

### 3. 牛虻：哲学作为一种使命

苏格拉底把雅典比作一匹**高贵而昏睡的骏马**，把自己比作叮在马背上让它清醒的**牛虻**。神派给他的使命就是每天在街上拉住人追问：「你说的正义、勇敢、虔诚，到底是什么？」——他因此得罪全城，但他宁可死，也不停止省察。

### 4. 名句：「未经省察的人生不值得过」

面对死刑威胁，苏格拉底拒绝求饶、拒绝停止哲学活动的交换条件，说出全书最著名的一句：**「未经省察的人生是不值得过的。」**（另一通行译法：「未经审视的人生不值得过。」）

### 5. 论死亡：一个二难推论

死刑何足惧？苏格拉底给出两种可能：**死亡或是无梦的安眠**（无人会抱怨睡了个好觉），**或是迁居到另一个世界**（可以与荷马、赫西俄德这些先贤终日论道——他一生的乐事）。两样都不坏。

### 6. 结尾

**「分手的时候到了：我去死，你们去活；谁的去路好，唯有神知道。」**

## 五、怎么读（建议读法）

1. **篇幅很短**（通行中译本正文约几十页），一次读完，比读一篇长文还快；
2. **选一个可靠的译本**，重点读三处：牛虻比喻、「未经省察的人生」段落、结尾诀别——这三处是两千多年来被引用最多的段落；
3. 别当历史课读，**当一场对话读**：每读到苏格拉底反问，停下来替对方想一个答案，再往下看；
4. 读完 1000 字以内、一本一投，投给读书汇 👉 [提交读书汇读后感](https://twpitpbt.jsjform.com/f/ASQzl3)。
