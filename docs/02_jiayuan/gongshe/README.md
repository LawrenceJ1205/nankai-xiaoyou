> **隶属关系**：← 本聊吧隶属于 **🔍 [我的南开家园](02_jiayuan/README.md)** 板块（核心板块 · 线上·家的客厅）

> **一句话定位**：南开人喜事、趣事、新近获得的成就与奖励、各地校友会活动通知、南开小友板块推荐与答疑 —— 一个有温度、有秩序的综合社区。

## 🎯 这里有什么？

南开公社是整个南开小友的**情感主线**，承担四件事：

| 板块 | 用途 | 谁可以发 |
|---|---|---|
| 🎉 **校友喜事** | 升职、获奖、出书、宝宝出生、结婚纪念 | 当事人或同学代发 |
| 🏆 **校友成就** | IPO、技术突破、国家级荣誉 | 当事人/校友会推荐 |
| 📅 **各地校友会活动** | 周年庆、沙龙、回校访问 | 校友会秘书处 |
| ❓ **板块答疑** | 对其他板块的提问与建议 | 全员 |

## ✍️ 我的南开故事（500 字以内模板）

> 这是南开公社的"主旋律"卡片，每篇按以下结构写：

```
我的南开故事（500 字以内）

1. 我的南开身份：届别 / 学院 / 现职
2. 触发回忆的"那一瞬间"（物品 / 气味 / 人 / 场景）
3. 我与南开某段故事的细节（400 字以内）
4. 这个故事对今天的我意味着什么（100 字以内）
5. 我最想在哪个年代 / 院系的校友面前分享（5 字以内标签）

提交渠道：南开公社微信群 / docsify 投稿表单
```

投稿被采用后会**永久留痕到本目录**，并被收录进每月《南开小友·公社月刊》。

## 🛡️ 群规七条（红线）

1. ❌ 不讨论政治、宗教、民族
2. ❌ 不发布广告、微商、招聘（招聘走"允能南开人"、创业走"小南创吧"）
3. ❌ 不涉及未公开上市/未公开融资细节（走"小南创吧"）
4. ❌ 不发布未授权的他人照片 / 视频 / 隐私信息
5. ❌ 不发布未成年人的个人信息
6. ✅ 校友会内禁止"排名 / 攀比 / 投票"——一视同仁
7. ✅ 失信被执行人禁止加入社群

违反任一条，群管理员会**温和提醒 → 移出**。
