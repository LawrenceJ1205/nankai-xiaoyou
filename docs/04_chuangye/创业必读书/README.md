## 一、这一辑的由来

板块最早的 Demo（《南开小友 Demo版.pptx》第 22 页）在「南开人创业」下就写了「📚 创业经典书籍」四个书名：**《精益创业》《里程碑》《纳瓦尔宝典》《小而美》**。

这四本是**设计时就想收的书**，但一直散在别处——《里程碑》的 MVP 内容单独成页，《纳瓦尔宝典》的内容混在「大咖说创业」里，另外两本始终没有落页。本辑把它们收拢，并按同一体例重做：

**版本信息（只留原书名 + 作者／传主身份）→ 这本书解决什么问题 → 核心框架 → 可上手工具 → 与其他书的分工 → 南开人的用法**

## 二、四本怎么排：一条阅读路线

> ⚪ **编者归纳**。顺序不是“重要程度”，而是“**从哪本开始最省力**”。

| 顺序 | 书 | 一句话读法 | 状态 |
|---|---|---|---|
| ① | [《精益创业》](04_chuangye/创业必读书/精益创业.md) | 先学**怎么把猜想变成可验证的实验**——这是所有“科学创业”的地基 | ✅ 已精读 |
| ② | [《里程碑》](04_chuangye/创业必读书/里程碑.md) | 再把实验装进**中国本土的五步框架**——需求 / 解决方案 / 商业模式 / 增长 / 壁垒 | ✅ 已精读 |
| ③ | [《纳瓦尔宝典》](04_chuangye/创业必读书/纳瓦尔宝典.md) | 前两本解决“怎么试”，这本解决“**杠杆压在哪、往哪个方向积累**” | ✅ 已精读 |
| ④ | 《小而美》 | 讲**不靠融资、持续盈利的经营法**——“一人公司 / 小团队”那条路 | ⏳ 待收录 |

**一句话串起四本**：

- 《精益创业》给你一套**科学方法**；
- 《里程碑》把它**翻译成中文语境**，并补上中国本土案例；
- 《纳瓦尔宝典》告诉你**时间与杠杆该投在哪里**；
- 《小而美》给出**另一种活法**——不必长成独角兽。

> 前三本层层递进：**先会做实验（①）→ 再懂中国商业怎么走（②）→ 最后决定把命押在哪个方向（③）**。

## 三、每本页的固定体例（六段）

| # | 段落 | 作用 |
|---|---|---|
| 1 | **版本信息表** | 只两项：**原书名** + **作者／传主身份**——能对上版本即可，不堆出版社 / ISBN / 页数 / 定价 |
| 2 | **这本书解决什么问题** | 一句话说清它出现之前的行业困境 |
| 3 | **核心框架（颗粒度）** | 逐层拆解，含关键术语、数字与案例 |
| 4 | **可上手的工具 / 检查清单** | 读完能直接用的表格或清单 |
| 5 | **与其他两本的分工** | 本书**不负责**什么——避免把三本读成一团 |
| 6 | **南开人的用法** | 对本板块 / 在校生 / 创业者的具体建议 |

## 五、收录标准（4 条）

| # | 标准 |
|---|---|
| 1 | **经过检验**——出版 5 年以上并被真实案例反复验证；**例外**：其方法论有长期实证积累者（如《里程碑》源自 2019 年起、43 万人课程与上万失败案例） |
| 2 | **可上手**——能拆出工具、清单或判断标准，不是纯理念书 |
| 3 | **有中文版**——以中文阅读为主，**原版信息一并标出** |
| 4 | **宁缺毋滥**——不凑数；查不到的**原书名**标注缺口，不编 |
