## 一、这本书解决什么问题

⚪ **编者归纳**。它出现之前的困境是：普通人想创业，面前横着三道门槛——

1. **技术门槛**：不会写代码，做不了产品；
2. **组织门槛**：雇不起团队，一个人顾不了生产、获客、客服全线；
3. **资金门槛**：没有启动资金，烧不起试错。

李一舟的回答是：**AI Agent（智能体）把这三道门槛同时拆了**。不用代码、不用团队、不用资金，用「数字员工」搭一家**一个人运营、全流程自动化**的公司。书的副标题就叫「AI Agent 创富」——核心不是 AI 工具，是**用 Agent 把商业闭环跑起来**。

> **概念先分清**：普通 AI 工具是「你问它答」；AI Agent 是**可自主规划、调用工具、持续执行任务的数字员工**——这是全书的地基，也是「无人公司」与「用 AI 办公」的区别。

## 二、核心框架（颗粒度）

⚪ 依据原书公开目录与试读内容整理。全书五章，恰是一条**从引擎到变现再到管钱**的链路。

### 2.1 第一章 · 引擎：AI Agent 入门与落地

- **「小龙虾」的比喻**：作者把每个 AI Agent 称作一只「小龙虾」——他在 Claude Code 上搭的第一个 Agent 叫「小舟」，定位是**无人公司的负责人：替他管理所有的 AI 员工**（此为书中试读内容）；
- **Agent 能帮你干什么：四个真正值钱的场景**——书中反复强调，不是所有事都值得交给 Agent，只有**值钱场景**才值得搭；
- **零基础搭建你的第一个 AI Agent**——不需要编程，从指令（提示词）写起。

> 🔑 **结构要点**：无人公司的组织形态不是「老板＋一群员工」，而是**老板 → 管理型 Agent → 干活的一群 Agent**——人只对第一个 Agent 负责。

### 2.2 第二章 · 效率底层：工作流、产品与硬件

| 小节 | 一句话 |
|---|---|
| 一个人怎么做出一个产品 | 把产品开发拆成**可交给 Agent 的工序**，人做判断、Agent 做执行 |
| AI 硬件：你的 AI Agent 的身体 | Agent 不只活在对话框里——接上硬件与外部工具，才能「动手」 |
| 你的自动化生产线 | 把「需求 → 生产 → 交付」串成**自动化工作流**，7×24 小时自己转 |

### 2.3 第三章 · 流量引擎：个人 IP 打造

产品做出来没人知道，等于零。第三章把获客问题转成**个人 IP 问题**：

| 小节 | 一句话 |
|---|---|
| 为什么 IP 不是可选项 | 无人公司没有品牌背书，**你就是唯一的信任来源** |
| 定位：找到你的黄金交叉点 | 你擅长的 × 市场要的 × AI 放大得了的，三者交集 |
| 人设：不是装，是提炼 | 把你最值钱的那部分真实经验提炼出来，不表演 |
| **内容：10% / 60% / 30% 法则** | 爆款内容的工业化配方——10% 引流款 / 60% 干货款 / 30% 转化款（比例按各平台生态调） |
| 平台选择：2026 年去哪做 | 平台有时效性，跟着流量红利走 |

> **与「大咖说创业 · Dan Koe」的呼应**：Dan Koe 的「一人公司＝品牌＋内容＋产品」三件套，第三章几乎是它的 AI 时代中文实操版。

### 2.4 第四章 · 心法：思维模型与稳赢策略

- **流程优化：砍掉 80% 的无效工作**——先问「这件事到底要不要做」，再问「怎么让 Agent 做」；
- **思维模型：让 AI Agent 帮你做更好的决策**——把决策框架喂给 Agent，让它替你过筛；
- **稳赢策略：复利机制与无许可杠杆**——
  - **复利机制**：选那些「做一次、反复生效」的资产（内容、工作流、模板），不做「做一次、结一次」的零工；
  - **无许可杠杆**（permissionless leverage）：不需要任何人批准就能启动的杠杆——内容、代码、自动化工作流；这是全书与《纳瓦尔宝典》共享的概念。

### 2.5 第五章 · 财富底盘：管好你赚到的钱

| 小节 | 一句话 |
|---|---|
| 先搞清楚你有多少钱 | 个人与生意的账要分开、要看得见 |
| 财富思维：三个人教会我的事 | 转述对他影响最大的三个人的金钱观 |
| 一个参考框架：三个桶 | 把钱分进三个桶管理（安全 / 增值 / 机动，具体比例见原书） |
| 五个投资陷阱 | 赚到钱之后别在这五个坑里亏回去 |

> 🔑 **一句话串起全书**：**第一章搭员工（Agent）→ 第二章建产线（工作流）→ 第三章拉客户（IP）→ 第四章修心法（复利与杠杆）→ 第五章守财富（三个桶）**——从赚钱到守钱，闭环完整。

## 三、可上手的工具 / 检查清单

### ✅ 无人公司启动自检表

| # | 自问 |
|---|---|
| 1 | 我选的场景，是不是**真的值钱**？（不值钱的场景，Agent 再能干也白搭） |
| 2 | 这件事我能不能**写清楚指令**？（写不清楚＝还没想清楚，先别搭） |
| 3 | 流程里哪些环节**必须人来做判断**？（把这些挑出来，其余才交给 Agent） |
| 4 | 我有没有「做一次、反复生效」的**复利资产**？（纯零工模式不叫无人公司） |
| 5 | 我的 IP 定位处在**黄金交叉点**上吗？（擅长 × 需求 × AI 可放大） |

### ✅ 内容配比盘（10% / 60% / 30%）

拿自己最近 10 条内容对号：引流款几条？干货款几条？转化款几条？**全是干货款＝没人知道你；全是引流款＝留不住人；全是转化款＝没信用。**

## 四、与其他几本的分工

| 书 | 负责回答 | 不负责 |
|---|---|---|
| **《无人公司》** | **执行层怎么自动化**——Agent、工作流、IP、变现的 AI 时代打法 | 不教「该做什么方向」的科学验证（那是《精益创业》的事）；方法未经长周期检验 |
| [《精益创业》](04_chuangye/创业必读书/精益创业.md) | **怎么科学地试**——验证假设、MVP、转型 | 不涉及 AI 工具 |
| [《里程碑》](04_chuangye/创业必读书/里程碑.md) | **在中国怎么做**——五步框架与本土案例 | 不涉及 Agent 自动化 |
| [《纳瓦尔宝典》](04_chuangye/创业必读书/纳瓦尔宝典.md) | **杠杆压在哪**——专长、责任、判断力 | 「无许可杠杆」一词两家共通，纳瓦尔讲原理，本书讲 AI 时代的实操载体 |

> ⚪ **一句话定位它在这条书路上的位置**：前三本讲「**做什么、怎么试、往哪压**」，本书讲「**怎么让 AI 替你干**」——它是执行自动化的一环，不能替代方向判断。**方向错了，自动化只会加速亏损**——这句恰好要用《精益创业》来补。

## 五、南开人的用法

⚪ **编者归纳**，供参考：

| 对象 | 建议 |

| **想低成本起步的校友** | 不必先注册公司、先租办公室——按第二章「自动化生产线」先把一条最小工作流跑通，看它能不能自己转 30 天 |
