## 一、为什么单独立这一辑

「骄人南开校友企业 · 允公南开人」收的是**企业**（字段卡、行业矩阵、回馈记录）；「创业大咖方法论」收的是**外部方法论**（王兴、马斯克、纳瓦尔）；这一辑只做一件事：

**把已经走到公开市场上的南开创业者，一个人一个人地看清——他是怎么做人的、做成了什么、留下了什么话。**

《左传》有"三不朽"：

> **太上有立德，其次有立功，其次有立言，虽久不废，此之谓不朽。**

借过来放到创业上，就是三个问题：

| 维度 | 问的是什么 | 对应创业者的什么 | 为什么放在创业板块 |
|---|---|---|---|
| **立德** | 他是个什么样的人 | 底线、诚信、对员工/客户/社会的态度、关键处的取舍 | **创业先创人**。技术会过时，赛道会切换，只有"人"是长期变量 |
| **立功** | 他做成了什么事 | 技术突破、产品、产业价值、解决真问题 | 创业不是表态，是**交付**——没有立功，立德只是清谈 |
| **立言** | 他留下了什么话 | 公开可查的原话、方法论、对后学的判断 | **可被复述的才可被继承**——一句话能替一个年轻人省三年弯路 |

**三个维度是一条线，不是三顶帽子。** 顺序是：先立德（立住人）→ 再立功（做成事）→ 后立言（传下去）。所以本辑每家都按这个顺序写。

> **写作纪律**（同 [🎙️ 掌门人创业故事](04_chuangye/南开掌门人创业故事.md)）：事实层全部可查（年报 / 招股书 / 校方新闻稿 / 权威媒体专访）；**带引号者为当事人原话，查不到就不写**；每页末尾附来源。

## 四、收录标准（4 条，宁缺毋滥）

1. **必须是上市公司**（A 股 / 港股 / 美股，含 A+H），且**南开校友是创始人或核心掌舵人**——"校友名片"（如执业所在机构）不收；
2. **必须有明确的南开教育背景**（就读院系与年级可查），仅"联谊会成员企业"或"南开系资本被投"**不入本辑**（归口 [🏆 骄人南开校友企业 · 允公南开人](06_jiaoren/README.md) 的"口径分列"）；
3. **必须能查到公开的原话与事实**——立德、立功、立言三维，缺一维就标注缺口，**不编、不演绎**；
4. **市值与员工数以年报和交易所行情为准**，标注截至日期与来源。
