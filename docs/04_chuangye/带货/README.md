## 一、这一辑为什么单独立

「南开人创业」板块已有的几路——[大咖说创业](04_chuangye/大咖说创业/README.md)收**人物方法论**、[知名风投谈 AI 创业趋势和避坑](04_chuangye/知名风投谈AI创业趋势和避坑/README.md)收**投资人看势**、[创业案例分析](04_chuangye/案例研究/README.md)收**多视角拆解**、[创业ABC](04_chuangye/创业ABC/README.md)收**一条说透的通识**——讲的都是**认知与判断**。

## 三、收录标准与更新

1. **只收全链路闭环**——单点技巧不成篇；从选品或起号讲到售后复购、能直接照着做的才收；
2. **出处必标**——主理人提供的 AI 整理稿按站内惯例标信源 B 照录（只重排分段、表格重建，不逐条二次核实）；一手访谈、官方口径按 A／B／C 分层标注；
3. **与站内互链**——个人 IP 与内容打法对照 [姜玉洋案例研究](04_chuangye/案例研究/姜玉洋案例研究·把苏格拉底搬到短视频.md)；AI 工具（AI 客服、智能体）用法对照 [AI Agent 使用最佳实践](03_xinzhi/AI_Agent使用最佳实践/README.md)；
4. 每收一篇，同步三处：本页表格、左侧导航、[板块首页](04_chuangye/README.md)粘合剂表。

有合适的带货实操材料（自己趟出来的打法、值得照录的攻略），欢迎投给主理人。
