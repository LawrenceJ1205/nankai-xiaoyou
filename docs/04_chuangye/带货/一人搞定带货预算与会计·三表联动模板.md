以下为方法论底稿照录。

## 前提

面向**个人/小团队、不请会计**。核心思路是「**固定成本按月摊、变动成本按单算、一张表记到底**」——不用复式记账，用流水＋单件成本即可算清赚不赚钱。

## 一、先把成本分成两堆

### 1. 固定成本（不管卖不卖都要花，按月摊）

每月发生、和单量无关，单独记在「月固定开销」里：

| 项目 | 说明 |
|---|---|
| 店铺保证金 | 一次性，不算月成本，但要占用资金 |
| 设备/场地 | 手机、补光灯、支架、仓库或云仓月租 |
| 软件/工具 | 选品、剪辑、记账、投流订阅费 |
| 人工（自己） | 建议给自己记一笔「机会成本/工资」，别当自己没成本 |
| 证照、样品、杂项 | — |

### 2. 变动成本（每卖一单就发生，按单件算）

这是算净利的关键，逐件列：

| 项目 | 说明 / 易漏点 |
|---|---|
| 进货成本 | 货款，注意供应商可能另收采购运费 |
| 快递运费 | 偏远地区（新疆西藏）另加，别漏 |
| 包装材料 | 纸箱、气泡膜、胶带、赠品 |
| 平台技术服务费 | 按成交额抽，类目不同约 1%–5% |
| 达人/联盟佣金 | 若挂达人，按结算基数 × 佣金率 |
| 投流分摊 | 千川等广告费，摊到每一件 |
| 退货/仅退款损耗 | 按退货率摊到每单，最容易漏、最致命 |
| 补发/破损/售后 | — |

## 二、单件保本价公式（先算清楚再定价）

```
单件保本价 = 进货 + 运费 + 包装 + 平台抽成 + 达人佣金
          + 单件投流 + 退货损耗 + 售后分摊
单件净利   = 售价 − 单件总成本
净利率     = 单件净利 ÷ 售价
```

**退货损耗怎么摊**：假设退货率 20%，每 5 单有 1 单退回（可二次销售就扣运费包装，不可售就扣进货），把这部分损失平摊到成交的每一件上。新手最常犯的错就是只算「卖出那单」，不算退货，账面盈利实际亏损。

## 三、预算怎么做（一人版，按月）

### 1. 启动预算（开播前）

先盘「手里能拿出多少钱、能承受亏多久」：

- **一次性投入**：保证金 ＋ 设备 ＋ 首批进货 ＋ 样品；
- **周转备用金**：留足 1–2 个月固定开销和补货钱，别把钱全压进库存；
- **止损线**：提前定好「连续亏到多少就停/换品」，不无限追加。

### 2. 月度预算（分三块）

| 块 | 怎么控 |
|---|---|
| 进货/备货 | 小批量试，卖动再补，不压大库存 |
| 投流 | 设单日上限，ROI 不达标就停，不凭感觉加码 |
| 固定开销 | 每月固定项，能省则省 |

> **铁律**：投流费、进货费都要从「预计毛利」里出，先算单件净利为正，再投流；别用投流硬撑一个本身不赚钱的品。

## 四、一人记账：一张表搞定（流水＋月结）

不用会计科目，建一张 Excel/表格，分两个 sheet：

**Sheet1 每日流水（按单记）**

列：日期 ｜ 订单号 ｜ 售价 ｜ 进货 ｜ 运费 ｜ 包装 ｜ 平台抽成 ｜ 佣金 ｜ 投流 ｜ 退货/退款 ｜ 单件净利 ｜ 备注

每天花 10 分钟把订单填进去，手机表格即可。

**Sheet2 月度汇总**

- 总收入（成交 GMV）
- 总变动成本（进货＋物流＋包装＋抽成＋佣金＋投流＋退货）
- 月固定成本
- 月净利润 ＝ 总收入 − 总变动成本 − 月固定成本
- 关键比率：净利率、退货率、客单价、单件净利

### 每月只看 4 个数

1. **净利率**：是否为正、是否在目标区间；
2. **退货率**：超阈值说明选品/描述有问题；
3. **客单价 × 单件净利**：决定赚钱效率；
4. **现金流**：账上能不能撑到下一轮补货（账赚现金没了最危险）。

## 五、一人容易踩的 6 个坑

1. 只看 GMV：成交额大不等于赚钱，扣完成本退货可能亏；
2. 漏算退货和偏远运费，这两个是隐形出血点；
3. 投流不设上限，ROI 低于保本线还在烧；
4. 把保证金、设备当沉没成本不看，实际占用了周转金；
5. 不记自己的时间成本，忙一月一算白干；
6. 账面盈利、现金枯竭——退货、账期、囤货都会让利润变不成钱。

## 六、一句话口诀

> **固定成本按月摊，变动成本按单算**；
> **先算保本价再定价，投流只投赚的品**；
> **一张流水表、每月四个数，现金不断就不怕**。
