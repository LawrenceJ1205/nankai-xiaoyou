## 🎖️ 上市校友企业 · 立德 · 立功 · 立言 ⭐

> **📁 这是一个专辑 —— 点开进入。** 把南开校友创办的 **12 家上市公司**单独拎出来，**先看一张公司档案**（上市代码 / 市值 / 员工数 / 主营业务 / 回馈南开与社会），**再读创始人的三件事**：
>
> - **立德**——他是个什么样的人（底线、诚信、关键处的取舍）
> - **立功**——他做成了什么事（技术突破、产品、产业价值）
> - **立言**——他留下了什么话（公开可查的原话）
>
> 《左传》"三不朽"：**太上有立德，其次有立功，其次有立言，虽久不废，此之谓不朽。** 借到创业上，就是**南开创业人的完整人格自我塑造过程**——创业先创人，立住人 → 做成事 → 传下去。

## 🏫 五校系创投全景比较（把南开系放进坐标系）⭐

> 单看南开系，容易自满，也容易自卑——放进**清华 / 北大 / 复旦 / 浙大 / 南开**五校坐标系里，谁在“接力棒机制”、谁在“制度化成果转化”、谁在“个人英雄主义式垂直深耕”，一目了然。
>
> 一句话结论：**五校系创投的最终分野，不在于谁投出了更高的回报倍数，而在于谁能率先完成从“个人判断”到“系统能力”的跃迁**。

| 学校 | 核心气质 | 典型出手逻辑 |
|---|---|---|
| 清华系 | 技术源头纵深卡位，校友闭环接力 | 先判断技术代际，再找人；校友基金投种子，专业芯片基金接成长期，国家资本接重资产 |
| 北大系 | 成果转化制度化，实验室直接孵化 | 元培基金、燕缘创投、燕缘孵化器构成“实验室→孵化器→资本市场”的体制化链条 |
| 复旦系 | 商科底蕴＋成长期判断，做“资本合伙人” | 复旦经院 / 管院背景创始人，擅长成长期企业的战略与资本运作陪伴 |
| 浙大系 | 学院派长期主义＋泛浙大生态 | 与科学家创业者“聊得来”，以浙大母基金撬动生态，参股不控股 |
| 南开系 | 个人英雄主义＋垂直深耕 | 盛希泰、郑伟鹤、刘道志等“单点重仓”，以个人判断力驱动机构风格 |
