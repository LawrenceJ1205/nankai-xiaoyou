## 🎖️ 上市校友企业 · 立德 · 立功 · 立言 ⭐ 🆕

> 把南开校友创办的**上市公司**单独拎出来，**先看一张公司档案（上市代码 / 市值 / 员工数 / 主营业务 / 回馈南开与社会），再读创始人的三件事**：
>
> - **立德**——他是个什么样的人（底线、诚信、关键处的取舍）
> - **立功**——他做成了什么事（技术突破、产品、产业价值）
> - **立言**——他留下了什么话（公开可查的原话）
>
> 《左传》"三不朽"：**太上有立德，其次有立功，其次有立言，虽久不废，此之谓不朽。** 借过来放到创业上，就是**南开创业人的完整人格自我塑造过程**——创业先创人，立住人 → 做成事 → 传下去。
