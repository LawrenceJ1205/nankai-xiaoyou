## 二、每篇案例的固定体例

本辑不写传记，也不写成功学。每篇按同一套骨架推进，保证**结论是从材料里长出来的，不是先有结论再找例子**：

### 体例一 · 研究体例（默认）

| 段 | 回答什么 |
|---|---|
| **研究框架** | 这篇要回答的**一个具体问题**（不是“他为什么成功”这种大而无当的题） |
| **时代层** | 这个人所在的那一代创业者，**认知层级**和别人差在哪 |
| **创业者层** | 他本人的**判断力**是怎么被现实一次次校准出来的 |
| **投资人层** | 押他的人**凭什么敢**、托底到什么程度、又在等什么新证据 |
| **对照层** | **错过的人**事后怎么复盘——遗憾往往比成功更能说明问题 |
| **综合洞察** | 提炼出**可迁移的几条**（对投资人、对创业者分别意味着什么） |
| **开放问题** | 明确写出**本文没有答案**的追问，留给下一批材料 |
| **引用索引** | 逐条标明**观点出自谁、哪一次访谈／复盘** |

### 体例二 · 哈佛案例体（教学用 · 材料足够厚时启用）

当一篇案例的一手材料足够厚、且**存在可供讨论的真实分歧**时，改用哈佛商学院案例体——**正文只给事实，把结论与判断题留给读者**：

| 段 | 回答什么 |
|---|---|
| **场景（Opening）** | 用一个**具体时刻**切入，不做背景铺垫 |
| **Case 正文** | 只呈现事实、场景与当事人**原话**，**刻意不下结论** |
| **决策点（Decision Point）** | 把当年的选择**摊在读者面前**，不预告答案 |
| **Exhibits** | 时间线／对照表／**金额分歧**／自述索引（**含可信度分级 A/B/C**） |
| **Discussion Questions** | MBA 级讨论题，按 **判断 → 诊断 → 方法 → 处方与迁移** 四组递进 |
| **Teaching Note** | 分析切口 + 未闭合追问 + **材料局限自陈**（转述、冲突、成功者偏差） |

> **为什么要写“开放问题／材料局限”**：一份研究如果什么问题都回答完了，它大概率是编的。**把边界画出来，比把话说满更有用。**
>
> **为什么要把“结论”从正文里拿走**：结论一旦写进正文，读者就只剩“同意／不同意”两种反应；拿走之后，才有第三、第四种可能。**这正是哈佛案例体的全部用意。**

## 四、怎么用这一辑

- **先做判断题**：读完前先问自己一句——「我不看结论，能推出同样的判断吗？」推不出，说明缺的是输入，不是运气；
- **再做换位题**：同一份材料，站在**创业者**位置上读一遍，再站在**投资人**位置上读一遍，答案会不一样；
- **带读／自测用讨论题**：**哈佛案例体**的篇目文末附 8 道 MBA 级讨论题，可用于读书会现场带读，也可个人限时写作——**本辑不提供标准答案**，带读注记里的分析切口是**可被推翻的假设**，不是答案；
- **带着问题去聊吧**：本辑不收评论，评论去 [🎯 小南创吧](04_chuangye/chuangbar/README.md)——每周二 20:00–21:30「大咖方法论深读」值班；
- **想加案例**：欢迎推荐——附上**公开访谈 / 演讲实录 / 投资人复盘 / 一手报道**即可交主理人评估。

> **收录标准**：① 必须有**多视角**的一手材料（只有自述、没有旁证的不单独立篇）；② 每条观点**可回溯到出处**；③ 允许残篇，但**宁可缺、不编**；④ 与 [🧠 大咖说创业](04_chuangye/大咖说创业/README.md) 的分工——**那边收“他怎么想”，这边收“别人怎么看他、怎么验他”**；⑤ **转述材料须标明级别**——A 本人采访实录／B 第三方现场转述／C 媒体演绎，级别 B、C 不得作为原话直接引用。
