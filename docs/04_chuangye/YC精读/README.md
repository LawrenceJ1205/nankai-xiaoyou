## 一、这一辑为什么单独立

外部方法论不少，但 YC 有三样别处拿不到的东西：

1. **数据**——每年看上千家被投公司，趋势是从名单里**数出来**的，不是猜出来的；
2. **一手**——官方播客与对谈全程录播，能追到**原话**，不必依赖二手转述；
3. **前沿**——讲的人就在 AI 创业最前排，说的常是**下个季度才扩散开的判断**。

所以本辑只做一件事：**把一手源逐集吃透，标清哪句是原话、哪句是本平台的推断。**

## 四、更新机制

**巡检（每周一次）**：扫这三个入口有没有新集——The Lightcone 播客、Startup School、官方 Request for Startups；产出一份**候选清单**（标题 / 日期 / 时长 / 主题 / 与站内三板块的对应点），**由主理人勾选**，不自动落页。

**落页（勾选后）**：按「信源分层 ＋ 原文还原 ＋ 校勘附录」体例成页，并同步**四处**——

1. 本页第三节表格
2. 左侧导航（板块导航里的「📚 YC 精读」组）
3. [板块首页 · 创业大咖方法论集成](04_chuangye/README.md)
4. [小南创吧 · 周二深读讲义](04_chuangye/chuangbar/README.md)

**合规**：本辑只做**公开信息**的整理与评述，不代表 YC 官方立场，南开小友与 YC 无隶属关系；引用一律标注来源层级。
