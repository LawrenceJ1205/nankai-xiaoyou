## 📋 BP 投递工单（保密 · 实名）

> **投递入口**：👉 [提交创业项目商业计划书](https://twpitpbt.jsjform.com/f/nktLE3)（实名 · **需登录金数据账号** · **每账号限投 1 次** · 附件限 PDF 20MB）

**投递字段（与线上表单一致，共 9 项；★ 为必填）**

```
BP 入库工单（保密 · 实名）

1. ★ 项目名称
2. ★ 一句话亮点（≤ 30 字）
3. ★ 所属行业
4. ★ 融资阶段（未融资 / 天使轮 / 风险投资 / Pre-A / A 轮及以后）
5. ★ 项目简介（200–300 字）
6. 创始人 / 团队简介
7. 商业计划书附件（PDF，≤ 20MB）
8. ★ 联系方式
9. ★ 保密与信息使用条款（必选同意，未勾选无法提交）
```

> 🔒 **提交前须勾选「保密与信息使用条款」**：本表仅用于**导师点评**与**经您授权的校友间交流**；**未经您的逐次书面同意，不会将 BP 原件或其中任何信息提交、转发、推荐给任何第三方**（含投资机构、校友企业）；**不收融资成功费、不做撮合、不承诺任何融资结果**；资料编号化保管、文件名不体现公司名称；**您可随时要求删除已提交的全部资料**。

> ⚠️ **投递表不收集、也不对外任何金额类信息**——不填融资金额、不填估值、不填出让份额。
> 融资条款由项目方与投资机构**私下交换**；本板块只提供“彼此认识”的机会，不提供“撮合”的动作。

**信息三级分级（谁能看到什么）**

| 级 | 内容 | 可见范围 |
|---|---|---|
| **L1 原件** | BP 全文（含项目方自行写入的条款） | 主理人 + 已签保密承诺的值班导师；编号化存档，文件名不带公司名 |
| **L2 台账** | 业务字段 + 融资阶段 | 内部项目池，仅主理人 |
| **L3 公开** | 项目名 + 一句话亮点 + 行业（**经项目方逐次授权后**） | 站内 / 创投圈简报 |

**铁律**：**L1 永不进公开页**；**L3 永不出现金额、估值、份额**。

**转交规则（底线）**

- **一次授权只对一次**：把 BP 提交给任何第三方前，须取得项目方**逐次书面同意**；本板块只做「**保管 + 送达**」，不做「推荐」。
- **不说“值得投”**，只说“有这么一个项目”。
- **不经手资金、不代收、不分成**，也不以融资结果作为考核。

**值班导师评分卡（5 维各 5 分 · 纯辅导口径）**

- 创始人（团队匹配度）
- 赛道（市场天花板）
- 商业模式（飞轮逻辑）
- 财务模型（Unit Economics 是否算得清）
- 风险点（合规 / 可执行）

总评：□ 建议继续打磨　□ 建议调整定位　□ 建议先补数据佐证

> ⚠️ **本栏目目前为空**——原「第 001 期」系**虚构样稿**（化名 Project H，无真实来源），为避免以示例充案例，已**撤下**。**第 001 期只留给真实的南开创业失败故事。**

**投稿要求（三条硬线）**

1. **真实**——须为本人或团队的真实经历，拒绝虚构、拒绝"看起来像"；
2. **去标识化**——公司名、人名、客户名、合同金额一律脱敏（平台代为处理）；
3. **可核对**——投稿人须留可联络方式，编辑组会做一次真实性确认（不公开、不对外）。

## 🛡️ 红线

- **四不**：**不推荐**（不说“值得投”，只说“有这么一个项目”）· **不背书**（校友身份是**认识**的理由，不是**相信**的理由）· **不碰钱**（不经手、不代收、不分成）· **不公开**（金额、估值、份额概不对外）
- 不问在校生身份信息；项目组不提供基金保荐，**也不承诺任何融资结果**
- **BP 原件不转交**，除非项目方**逐次书面同意**；转交只做送达，不做撮合
- 失败案例必须去标识化：明确删除公司名、人名、合同金额
- 值班导师回避：所投 / 在的公司项目由其他导师点评；导师须先签**保密与不留存承诺**
