## 四、怎么用这一辑

- **先看一句话**：第三节表格里的"一句话"就是每篇的题眼，先判断要不要深读；
- **再看案例**：每篇都带**公开可查的案例与失败经验**，不是励志文；
- **对应课堂**：[🎯 小南创吧](04_chuangye/chuangbar/README.md) 每周二 20:00–21:30「大咖方法论深读」值班，用本辑当讲义；
- **想加人**：欢迎推荐——附上**公开访谈 / 演讲 / 一手底本**即可交主理人评估。

> **口径**：本辑依据**公开访谈、演讲实录与公开报道**整理；引号内为当事人原话，其余为整理表述；查不到来源的**宁缺不编**。
