## 一、这一辑为什么单独立

「南开人创业」板块里已有三路内容：[大咖说创业](04_chuangye/大咖说创业/README.md)收**人物长文**、[知名风投谈 AI 创业趋势和避坑](04_chuangye/知名风投谈AI创业趋势和避坑/README.md)收**逐集精读**、[案例研究](04_chuangye/案例研究/README.md)收**多视角拆解**。

还缺一格：**一条就能读完的通识**——某位掌门人或投资人把一件创业常识**一次说透**的那段话。本辑就收这种内容，按**词条卡**体例落页：

- **快**：一条一页，两三分钟读完；
- **准**：原话照录、出处必标，转写存疑处设编者注、不擅改；
- **连**：每条与站内长内容（案例、专辑）互链，读完能顺藤深读。

## 四、收录标准与更新

1. **只收说透了的**——一段话把一个通识讲完整，掐头去尾不成条的不要；
2. **只收有公开出处的**——出处必标（公众号、播客、访谈），查无出处不收；
3. **转写稿照录存异**——语音转写的明显误差**不擅改**，设编者注待核；
4. 每收一条，同步三处：本页表格、左侧导航、[板块首页](04_chuangye/README.md)粘合剂表。

有合适线索（哪位掌门人/投资人把哪个创业常识说透了），欢迎投给主理人。
