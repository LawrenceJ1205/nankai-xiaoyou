## 一、这一页讲什么

高校科研人员带成果创业，**第一道关口不是见投资人，是职务发明的归属**——按法规，职务科技成果所有权默认归单位。不先与学校把权属谈成**书面协议**，融资尽调的第一关就过不去；本条把政策底线与三条正路一次讲清。

---

## 二、政策原文要点（🔵 官方文件照录）

> 🔵 以下为科技部官网公布的《试点实施方案》（国科发区〔2020〕128 号）条款原文，照录不改：

- 「国家设立的高等院校、科研机构科研人员完成的职务科技成果所有权属于单位。」
- 「按照科研人员意愿采取转化前赋予职务科技成果所有权（先赋权后转化）或转化后奖励现金、股权（先转化后奖励）的不同激励方式，对同一科技成果转化不进行重复激励。」
- 「试点单位可赋予科研人员不低于10年的职务科技成果长期使用权。」
- 「试点单位与科技成果完成人（团队）应签署书面协议，合理约定转化科技成果收益分配比例、转化决策机制、转化费用分担以及知识产权维持费用等。」
- 「高等院校、科研机构对其持有的科技成果，可以自主决定转让、许可或者作价投资，不需报主管部门、财政部门审批。」

## 三、拆解（⚪ 编者归纳，非政策原文）

| 要点 | 说明 |
| ---- | ---- |
| **为什么必须在融资前** | 权属不清的成果，投资机构尽调第一关就过不去——**先去人事处与技术转移中心，后见投资人** |
| **三条正路** | ① 学校**作价投资入股**（学校成为股东）；② 学校**转让**给科研人员；③ 学校**许可**给科研人员的企业（所有权留校、企业拿使用权）——三条路之外没有第四条正路 |
| **试点政策红利** | 分领域选择的 40 家试点高校院所，可走「先赋权后转化」：科研人员与单位成为**共同所有权人**；赋权须在单位内公示，公示期不少于 15 日 |
| **作价入股的后续考量** | 学校持股比例过高会稀释团队、影响后续轮次——协议里就应写清未来的回购或稀释安排 |
| **各校比例不同** | 成果转化收益的校方分成比例各校制度不一，**以本校技术转移中心口径为准**（本条不引具体数字） |
