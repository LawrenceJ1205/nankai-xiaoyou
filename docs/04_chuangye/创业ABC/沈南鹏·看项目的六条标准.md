## 一、这是谁

**沈南鹏**，1967 年生于浙江海宁，上海交通大学本科、耶鲁大学商学院硕士；携程旅行网、如家连锁酒店联合创始人。2005 年创立红杉资本中国基金（红杉中国，现英文名 HongShan），代表投资案例包括美团、京东、字节跳动、拼多多等；多次位居《福布斯》全球最佳创投人榜（Midas List）榜首，是中国风险投资行业代表性投资人之一。

## 二、要点实录

> 🟡 六条的**骨架句与核心表述**出自沈南鹏本人在公开报道中的自述（21 世纪经济报道 2018 年报道、凤凰网转载等，多源一致），以下照录：

「我选项目有六条秘诀，分别是：看人、模式、执行力、客单量、效率、数据。创始人和团队的能力很重要，但更重要的是人要靠谱、诚信，不要忽悠投资人。」

「执行力是决定创业公司在初创期后能否融到钱的关键节点，因为没有执行力，所有的 idea、所有的远景目标，都是空谈。」

「（客单量）之前所有的因素都会在客单量上表现……只要客单量足够好，融资就不成问题。」

> 🟡 六条各自的展开，底本（无署名转述稿）与公开报道互有详略。以下为**对勘后的要点实录**——属转述归纳，**不作沈南鹏原话直引**：

| # | 看 | 意思 | 佐证例（出自公开报道／转述稿） |
| - | -- | ---- | ---- |
| 1 | **人** | 能力是后话，**靠谱、诚信、不忽悠投资人**才是入场券 | 「台面上的话是看创始人和团队的能力，抽屉里的话是人要靠谱」 |
| 2 | **模式** | 不求大而全，求**独特可行、能形成壁垒**的那个点——「那件事只有你能做，别人轻易抄不走」 | 满大街都是的生意不叫模式，叫重复 |
| 3 | **执行力** | 决定初创公司早期之后**能否拿到钱**的关键；没有执行力，一切愿景都是空谈 | 执行力的本质不是搞大动作，而是在最粗糙的条件下也能步步推进 |
| 4 | **客单量** | 团队、模式、执行力的**市场验证结果**——投资人越往后越不听你怎么说，只看用户怎么买单 | 客单量是那个不会说谎的裁判（转述稿语） |
| 5 | **效率** | 客单量看规模，效率看**质量**——花更少的资源跑出更高的价值 | 同样花 100 块获客，A 回款 80、B 回款 200 |
| 6 | **数据** | 投资决策必须落在**经得起交叉验证的真实数据**上，不是 BP 里的推算 | 直接打开后台看复购率、留存率、获客成本 |

## 三、拆解（⚪ 编者归纳，非原话）

- **六条是一条漏斗**：人是入场券（不过关免谈）→ 模式找唯一切口 → 执行力验能不能干出来 → 客单量验市场买不买账 → 效率验质量 → 数据把前面全部钉死。前三条看「你怎么说」，后三条看「账怎么走」。
- **与徐新卡互为镜像**：[徐新](04_chuangye/创业ABC/徐新·优秀创业者的特质.md)讲的是「先看到」（杀手的直觉），沈南鹏讲的是「看到之后怎么被验证」——直觉是入口，六条是关卡。
- **转述稿的落点**（作者语，非沈南鹏原话）：六条骨子里只指向一件事——你能不能拿出一条**让投资人无从质疑的证据链**。
