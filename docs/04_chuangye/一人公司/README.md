## 一、这一辑为什么单独立

「一人公司」在站内散落多处，各管一段：[Dan Koe 的一人公司](04_chuangye/大咖说创业/DanKoe.md)讲**人物原型**，[《无人公司：AI Agent 创富》](04_chuangye/创业必读书/无人公司·AIAgent创富.md)讲**书**，[创业ABC](04_chuangye/创业ABC/README.md)讲**通识词条**，[带货 · 一人搞定预算与会计](04_chuangye/带货/一人搞定带货预算与会计·三表联动模板.md)讲**单人生意的实操 SOP**，[📚 知名风投专辑候选池](04_chuangye/知名风投谈AI创业趋势和避坑/README.md)里还压着「单人创始人的时代」「一个人做出 400 倍产出」两集一手源。

缺的是一格专门回答：**谁适合做、从哪切入、第一步怎么走**。本辑把这个问题单独立住，后续可继续纳入同题供稿与一手对谈。

## 三、收录体例

1. **原帖照录、只分段**：主理人供稿逐段照录，文字不增删；原文自带的分节句提升为二级标题，不另补小标题、不加评论层、不落对照表。
2. **信源分层**：稿中数据与政策表述按供稿口径照录，页头「材料说明」自陈未逐项加注公开来源；引用前请回官方口径核实。
3. **不与其它栏目重复**：人物原型归大咖说创业、书归创业必读书、通识归创业ABC、实操 SOP 归带货、一手趋势归知名风投专辑；本辑只收**路径判断**。第 2 篇虽同写 Dan Koe，但大咖说创业那篇是「品牌＋内容＋产品」方法论梳理，本辑这篇是个案数据、模型边界与 Eden 挫折的深描，两者分工不重。
